# 地方版 予算ビュー（local-gov）

国の予算可視化（本家 `team-mirai-volunteer/rs-vis`）をベースに、自治体の予算を可視化する「地方版 ○○予算ビュー」を作るための作業フォルダ。

## 方針

- **1本のコードで複数自治体に対応する**。自治体ごとの違いはデータと設定で切り替え、ブランチは分けない。
- **最初の事例は福岡県**。1件目は具体的に作り込み、2件目の自治体に着手する時点で共通化を本格的に進める。
  - ただし1件目から、自治体名・データの置き場所・金額単位などは定数や設定に集め、ハードコードを散らさない。
    （例外: 「データについて」ページの数字の作り方・検算の方法の説明文は、MVP では福岡県の資料に合わせてページに書く。
    2件目の自治体のときに index.json に移す。tasks/20261106_1327_地方版サンキー図の画面とグラフの設計.md 4.2）
- 本家との差分をできるだけ小さく保ち、本家の改善を取り込み続けられるようにする。

## ブランチ運用

| ブランチ | 役割 | 更新方法 |
|---|---|---|
| `main` | 本家 `main` のミラー。直接変更しない | 本家に追従して fast-forward のみ（`gh repo sync` / `git push origin upstream/main:main`） |
| `local-main` | 地方版の本流（GitHub の既定ブランチにする予定。2026-11-06 時点で未設定） | 作業ブランチから PR でマージ |
| `feat/*` `fix/*` `docs/*` | 個別作業 | `local-main` から worktree で切る（`../rs-vis-fukuoka-<短い名前>`）。未マージのブランチの上に重ねるときはマージの順番を PR に書く |

本家の取り込み: `main` を同期 → `main` → `local-main` の PR を作って衝突を解消。

リモート: `origin` = フォーク（bakumon1107/rs-vis-fukuoka）、`upstream` = 本家（team-mirai-volunteer/rs-vis）。本家への push・PR は行わない。

## このフォルダの構成

```
docs/local-gov/
  README.md   … 方針・ブランチ運用・ロードマップ（恒久的な文書）
  knowhow/    … 自治体をまたいで使える調査・作業のノウハウ（新しい発見があれば追記する。テストと回帰の運用も）
  tasks/      … 設計・調査・計画（YYYYMMDD_HHMM_タイトル.md）
  fukuoka/    … 福岡県固有の調査（入口ページ早見表・資料の癖・調査の記録）とデータの作り方
  本家指摘候補.md … フォーク元のコードで見つけた問題と、main から切った1コミットの修正ブランチの一覧
```

**ノウハウの蓄積ルール**: 調査や作業で分かったこと（どこに何があるか・ファイルの見分け方・落とし穴・やってみて効果がなかったこと）は、その都度 `knowhow/`（自治体共通）か `<自治体>/README.md`（自治体固有）に書き足す。同じ調査を二度しないため。

地方版の作業文書は本家の `docs/tasks/` ではなくここに置く（本家取り込み時の衝突回避と、文書の埋没を防ぐため）。

## 地方版のサイトとして出す（版の切り替え）

デプロイの環境変数 `NEXT_PUBLIC_SITE_EDITION=local`（と `NEXT_PUBLIC_LOCAL_GOV_ID=fukuoka-pref`）で、サイト全体を「予算ビュー＠福岡県」にする。
未設定なら本家と同じ国版のまま（CI・本家の e2e はこちらで回る）。ビルド時に埋め込まれるので、変えたら再ビルドする。
ローカルで地方版を見るときは `.env.local` に同じ値を書いて dev サーバーを起動し直す。

- `middleware.ts` が国版のページを `/` へ、`/api/**` と国のデータ・画像を 404 にし、`/` を `/local/<自治体>` へ向ける（許可リストは `app/lib/local-gov/site-edition.ts`）
- 名前・運営者・連絡先・配色は `app/lib/local-gov/site.ts`。外枠（ヘッダー・フッター）は `client/components/local-gov/LocalSiteShell.tsx`
- 本家のファイルで変えたのは `app/layout.tsx` だけ。本家を取り込むときはここの衝突と、本家が `middleware.ts` を作っていないかを確かめる
- GA は `NEXT_PUBLIC_GA_MEASUREMENT_ID` を明示したときだけ読み込む（未設定で本家のプロパティに送らない）

設計: [tasks/20261127_1752_サイト全体から国版を外す設計.md](tasks/20261127_1752_サイト全体から国版を外す設計.md)
