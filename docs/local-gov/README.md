# 地方版 予算ビュー（local-gov）

国の予算可視化（本家 `team-mirai-volunteer/rs-vis`）をベースに、自治体の予算を可視化する「地方版 ○○予算ビュー」を作るための作業フォルダ。

## 方針

- **1本のコードで複数自治体に対応する**。自治体ごとの違いはデータと設定で切り替え、ブランチは分けない。
- **最初の事例は福岡県**。1件目は具体的に作り込み、2件目の自治体に着手する時点で共通化を本格的に進める。
  - ただし1件目から、自治体名・データの置き場所・金額単位などは定数や設定に集め、ハードコードを散らさない。
- 本家との差分をできるだけ小さく保ち、本家の改善を取り込み続けられるようにする。

## ブランチ運用

| ブランチ | 役割 | 更新方法 |
|---|---|---|
| `main` | 本家 `main` のミラー。直接変更しない | 本家に追従して fast-forward のみ（`gh repo sync` / `git push origin upstream/main:main`） |
| `local-main` | 地方版の本流（既定ブランチ） | 作業ブランチから PR でマージ |
| `feat/*` `fix/*` `docs/*` | 個別作業 | `local-main` から worktree で切る |

本家の取り込み: `main` を同期 → `main` → `local-main` の PR を作って衝突を解消。

リモート: `origin` = フォーク（bakumon1107/rs-vis-fukuoka）、`upstream` = 本家（team-mirai-volunteer/rs-vis）。本家への push・PR は行わない。

## このフォルダの構成

```
docs/local-gov/
  README.md   … 方針・ブランチ運用・ロードマップ（恒久的な文書）
  tasks/      … 設計・調査・計画（YYYYMMDD_HHMM_タイトル.md）
  fukuoka/    … 福岡県固有の調査（データの出どころ・予算書の構造など）
```

地方版の作業文書は本家の `docs/tasks/` ではなくここに置く（本家取り込み時の衝突回避と、文書の埋没を防ぐため）。
