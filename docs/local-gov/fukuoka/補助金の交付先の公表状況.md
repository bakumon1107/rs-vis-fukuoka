# 福岡県 補助金の交付先の公表状況（2026-11-06 調査）

## 結論

- **全庁の補助金交付先一覧はない**。補助事業ごとに、所管課のページで「採択結果」「交付決定」「交付対象事業の公表」が散発的に出ているだけ。
- 載っている項目は事業によって違う:
  - **国の交付金を使う事業**（国の要綱で公表が求められるもの）: 事業主体・事業名・**総事業費・交付金額・県費・市町村費**まで載る（例: 強い農業づくり総合支援交付金、電源立地地域対策交付金）
  - **県単独の補助金**: 採択・交付決定した**事業者名だけ**（金額なし）が多い（例: 宿泊事業者生産性向上支援補助金、省エネ新製品開発支援補助金）
- したがって、国版の「事業 → 支出先」のような網羅的な層は作れない。分野ごとの付加情報として扱う。

## 調べ方

`/life/` 配下の全カテゴリ（約350）を巡回し、掲載ページ6,126件のタイトルを「交付決定・交付先・交付対象・採択・助成…実績」などで絞り込んだ（`scripts/local-gov/fukuoka-pref/research/crawl_life.py`）。
タイトルに出てこない公表（PDF の中だけにあるもの）は拾えていない可能性がある。
