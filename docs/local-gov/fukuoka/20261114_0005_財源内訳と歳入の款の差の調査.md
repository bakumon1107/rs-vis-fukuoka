# 財源内訳と歳入の款の差の調査（福岡県 R8 当初・一般会計）

調査日 2026-11-14。対象は `public/data/local-gov/fukuoka-pref/budget-2026-initial.json`（R8 当初予算に関する説明書 281298 の書き出し）と、説明書の画像。

## 1. 問い

一般会計の見方の左端（歳出の**財源内訳**の合計）と、歳入の**款**の額が合わない。

| 区分 | 歳出の財源内訳の合計 | 歳入の款 | 差（歳入 − 財源内訳） |
|---|---|---|---|
| 国庫支出金 | 210,506,089 | 国庫支出金 217,166,261 | **6,660,172** |
| 地方債 | 155,388,800 | 県債 168,724,500 | **13,335,700** |
| その他 | 275,532,511 | 分担金及び負担金・使用料及び手数料・財産収入・寄附金・繰入金・繰越金・諸収入 の計 324,777,602 | **49,245,091** |
| 一般財源 | 1,658,599,628 | 県税・地方消費税清算金・地方譲与税・地方特例交付金・地方交付税・交通安全対策特別交付金 の計 1,589,358,665 | **−69,240,963** |

（単位: 千円。書き出しの円単位の値を 1,000 で割ったもの。億円では 国庫支出金 2,105.1 ↔ 2,171.7、地方債 1,553.9 ↔ 1,687.2、
その他 2,755.3 ↔ 3,247.7、一般財源 16,586.0 ↔ 15,893.6）

## 2. 分かったこと（数字で確かめた）

- **3つの差の合計は、一般財源の差とちょうど一致する**（6,660,172 + 13,335,700 + 49,245,091 = 69,240,963 千円）。
  つまり、歳入では国庫支出金・県債・その他の款に入っているお金の一部を、歳出の財源内訳では**一般財源の欄**に数えている。
  ほかの欄へ移っている分はない
- **国庫支出金の差 6,660,172 千円は、歳入の節「物価高騰対応重点支援地方創生臨時事業費補助金」6,660,172 千円と千円の位まで一致する**
  （説明書 281298 p63（印字 -55-）、9款 国庫支出金 2項 国庫補助金 1目 総務費国庫補助金 4節。説明欄は「○物価高騰対応重点支援地方創生臨時交付金」）。
  - 歳出の財源内訳の「その他」の欄には財源の名前が印字される（諸収入・使用料及び手数料・財産収入・繰入金・分担金及び負担金・寄附金。
    R8 一般会計の歳出の全ページの OCR で確かめた）が、国の交付金の名前は1つもない
  - 歳出の説明欄の事項名に、この交付金や物価高騰対策の名前はない
  - よって、この交付金は歳出の財源内訳では**一般財源**の欄に数えられている（どの目に充てたかは説明書に書かれていない）
- **県債の差 13,335,700 千円は、歳入の県債の目「調整債」13,335,700 千円と一致する**（2026-11-08 に額の一致は確認済み）。
  上の合計の一致から、調整債も財源内訳では一般財源の欄に数えられている
- 同じ款の「地域未来事業費補助金」1,619,671 千円などほかの国庫支出金は、財源内訳の国庫支出金の欄に入っている
  （歳入の目の名前の款（総務費国庫補助金 → 総務費）と、財源内訳で使う歳出の款が違うことがあるので、款ごとには数億円ずつずれる。合計では差は上の1節だけ）

## 3. 分かっていないこと

- **なぜ一般財源に数えるのか**（制度上の扱いか、県の整理か）。説明書には書かれていない。確かめるなら県の財政課に問い合わせる
- **その他の差 49,245,091 千円のうち、繰入金以外の内訳**（下の 3.1）

### 3.2 諸収入・財産収入・使用料及び手数料をさらに分ける試み（2026-11-14 追記。節の金額・款ごとでは分けられない。目ごとに分けた結果は 3.3）

- **節の金額がそのまま財源内訳に出るか**: 歳入の節の金額が、歳出の財源内訳のその他の欄に同じ名前・同じ額で出てくるのは、諸収入 851,505・
  財産収入 22,027・使用料及び手数料 217,442 千円だけ。ほとんどの収入は複数の目に分けて充てられるか、複数の収入をまとめて1つの額で書かれている
- **款ごとに比べる**: 諸収入・使用料及び手数料の目の名前には款の名前が入る（「商工貸付金元金収入」「県土整備使用料」）。歳出の款ごとに
  その他の欄の額を足して比べると、別の款の事業へ回している分（歳入の目に款の名前がない・歳出の款と違う）が混ざり、差は款をまたいで打ち消し合う。
  - 諸収入: 歳入の目に款の名前のない分（宝くじ収入・雑入・延滞金・県預金利子など）が 19,537,940 千円あり、どの款に充てたかを名前で追えない
  - 財産収入: 歳入の目に款の名前がなく（財産貸付収入・利子及び配当金・不動産売払収入など 4,114,892 千円）、財源内訳では各款に 1,479,383 千円が出る
  - 使用料及び手数料: 差の大部分は県土整備（738,244 千円）。県土整備の使用料・手数料の17節の金額の組み合わせで差にちょうど一致するものはない
    （節の一部だけが一般財源か、別の款へ回している）
- 予算の見積りの資料（事業ごとの財源の充て方）がないと、これ以上は分けられない。確かめるなら県の財政課に問い合わせる

### 3.3 目ごとに分けて、受け皿のない収入を絞る（2026-11-14 追記）

財源内訳のその他の欄の（財源の名前, 金額）を目ごとに振り分けた（`scripts/local-gov/fukuoka-pref/research/funding_other_by_moku.py`。
232目のうち 228目で名前付きの金額の合計がその他の額と一致）。歳入の節と、歳出の目の金額を突き合わせた。

**ちょうど対応の付いた例**（歳入の節 = 歳出の目のその他の欄の金額）: 生活保護費返還金 257,551 = 扶助費、警察拘禁費用弁償金 222,917 = 一般警察活動費、
転貸債元利償還金 1,330,546 = 公債費の元金 1,259,417 + 利子 71,129、体育施設管理運営等負担金 100,619 = 体育施設費、
土地区画整理事業費納付金 82,800 = 土地区画整理費、林道災害復旧事業受託金 91,203 = 林道災害復旧費、公園使用料 80,441 = 公園費、
道路手数料 16,666 = 道路橋りよう総務費 など。対応の付いた組は 使用料及び手数料 25組・諸収入 25組・財産収入 2組。

### 3.4 歳入の説明欄の「課所管」の内訳で突き合わせる（2026-11-14 追記）

歳入の目の説明欄には、節の中身が「○○課所管 金額」の形で載る（財産貸付収入・利子及び配当金・雑入など）。この内訳は歳出の目の財源内訳の
その他の欄の金額とちょうど一致することが多い（利子及び配当金の 医療指導課所管 65,967 = 医務費、介護保険課所管 71,331 = 介護費、
こども未来課所管 113,514 + 子育て支援課所管 8,029 = 児童家庭総務費 121,543）。歳出の金額1件 = 歳入の内訳1〜3件の合計 の組を取り除いた
（`scripts/local-gov/fukuoka-pref/research/funding_other_match.py`）。

- **財産収入**（差 2,635,509）: 歳出 46件のうち 14件が課の内訳と対応。歳出のどの目にも受け皿のない大きなもの:
  文化政策課所管の財産貸付収入 851,440・土地建物売払代 811,405・企画総務課所管の財産貸付収入 455,331・財政課所管の利子及び配当金 369,575
  （計 2,487,751、差の 94%）。財産活用課所管の財産貸付収入 370,328 は、総務費の一般管理費の財産収入 372,707 と近いが一致しない
- **諸収入**: 大きな歳出の目（商業総務費 214,265,755 など）が多くの収入の合計なので、課の内訳でも組を取り切れない。受け皿のない候補は 3.3 と同じ
- **使用料及び手数料・寄附金**: 説明欄に課の内訳がなく（節そのもの、または「公社等外郭団体寄附金 974,000・その他一般寄附金 688,764」）、3.3 から進まない
- ここでも「候補」は受け皿が見つからないことからの推測。確かめるなら県の財政課に、財源内訳で一般財源に数えている収入の一覧を問い合わせる

### 3.5 なぜ一般財源に数えるのか（2026-11-14 にネットで調べた）

- **財政調整基金・減債基金の繰入金**: 使い道の決まっていない財源を一般財源、国庫支出金や県債のように使い道の決まった財源を特定財源と呼ぶ
  （石川県の財政資料）。財政調整基金は年度間の財源調整、減債基金は地方債の償還のための基金（浜松市の用語解説）で、取り崩した額の使い道が
  個別の事業に決まっていないので一般財源に数えるのが一般的な整理と見られる（福岡県の説明は見つからず。推測）
- **物価高騰対応重点支援地方創生臨時交付金**: 制度要綱では実施計画の事業費に充てる交付金で、ほかの自治体（気仙沼市）は事業の財源内訳で
  国庫支出金として示している。福岡県の R8 当初予算は財源内訳で一般財源に数えており、ほかの例と逆。理由は見つからない
  （当初予算の時点で実施計画の事業が決まっていない、などが考えられるが推測）
- **調整債**（2026-11-14 追記。ユーザーが示した資料と説明書で確かめた）:
  - 福岡県の説明書（281298）の「第4 地方債現在高調書」（印字 -471-〜-474-、文字層）では、県債は「1 普通債」（公共事業などの事業ごとの債）・
    「2 災害復旧債」・「3 その他」に分かれ、**調整債は「3 その他」**にある。同じ「その他」には 退職手当債・特別転貸債・災害援護資金貸付事業債・
    住民税等減税補填債・臨時税収補填債・臨時財政対策債・減収補填債 が並ぶ（特定の事業のための借金ではなく、財源の不足を補う性格の債が多い）。
    調整債の現在高は R6 年度末 26,227,486 千円 → R7 年度末見込み 37,821,860 千円、R8 年度中の起債見込み 13,335,700 千円（歳入の目と同じ額）
  - 広島県「財政用語一覧」https://www.pref.hiroshima.lg.jp/uploaded/attachment/331874.pdf の近い性格の債:
    「行政改革推進債: 地方公共団体が自主的に財政健全化に取組む場合，行財政改革による経費節減などにより，将来における財政負担の軽減効果額の範囲内で
    特別に発行できる地方債」「資金手当債: 財源不足額を補てんするために，通常の地方債が充てられる範囲を超えて，特別に認められる地方債」。
    総務省 地方財政審議会（令和5年2月17日）の地方債の同意の資料 https://www.soumu.go.jp/main_sosiki/singi/chizai/02zaisei02_04001397_00446.html
    でも、行政改革推進債は当初予算分の主な事業債（1,472億円）に挙がる
  - **推測**: 調整債は、行政改革推進債のように特定の事業に結び付かない（財源の調整に使う）債で、そのため財源内訳では一般財源に数えている。
    福岡県の資料に「調整債 = 行政改革推進債」などと書いたものは見つけていないので、確定ではない
- 出典: 石川県「財政のあらまし」https://www.pref.ishikawa.lg.jp/zaisei/zaisei/aramasi2010-06/documents/1-4.pdf 、
  浜松市「財政のすがた」用語解説 https://www.city.hamamatsu.shizuoka.jp/zaisek/sugata/finance_10/s015.html 、
  内閣府 臨時交付金 Q&A https://www.chisou.go.jp/tiiki/rinjikoufukin/juutenshien/r7QAsuisyou2.pdf 、
  気仙沼市 https://www.kesennuma.miyagi.jp/sec/s002/020/030/050/010/160/09/20251218zaiseika.pdf

## 4. ほかに合わない数字はないか（2026-11-14 に確かめた）

上の一般会計の財源内訳の差のほかに、合うはずの数字で合わないものはなかった。

- **会計ごとの歳入 = 歳出**: 一般会計・特別会計14会計とも差 0
- **特別会計の財源内訳 = 歳入の款**: 14会計とも、国庫支出金・県債・合計が千円まで一致（一般会計のような差はない）
- **会計間の繰出金と繰入金**（一般会計 ⇄ 特別会計）: すべて千円まで一致。繰出金は事項名・目名・節（「繰出金」の節）のどこかに出てくる
  （例: 一般会計の団体指導費の事項「特別会計繰出金」2,219 千円 = 就農支援 1,570 + 林業改善 649、小規模企業者等設備導入の
  一般会計への繰出 99,688 千円 = 公債費の事項 91,802 + 設備導入資金助成費の節 7,886）
  - 例外は一般会計の歳入「流域下水道事業繰入金」43,195 千円で、出し手の流域下水道事業は公営企業会計（書き出していない）
- 目ごとの検算（説明欄の合計・財源の合計・比較・節の合計）・項の合計（予算書）・款の合計（計上額調）は書き出しの時点で全件一致（作業報告・回帰テスト）
