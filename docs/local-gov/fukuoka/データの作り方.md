# 福岡県のデータの作り方

`public/data/local-gov/fukuoka-pref/`（共通 JSON 形式の正規化データ）を、県の公開資料から作り直す手順。
形式は [../tasks/20261106_0841_共通JSON形式の設計.md](../tasks/20261106_0841_共通JSON形式の設計.md)、テストの運用は [../knowhow/テストと回帰の運用.md](../knowhow/テストと回帰の運用.md)。

## 1. 入力を置く（リポジトリの外）

```
<dir>/
  pdf/<県サイトのファイル名>.pdf   … 説明書・議案・計上額調・決算書類など（URL は index.json の sources と各スクリプトの説明）
  ocr/r8-ippan/p0009.json …       … R8 一般会計の説明書の OCR（PP-OCRv6 ＋ セルの読み直し）
  ocr/r8-ippan-v4/…               … 同じ説明書の旧 OCR（中国語モデル。突き合わせの3つ目の読み取り）
  ocr/r8-toku/…・ocr/r8-toku-v4/… … 特別会計の説明書の同上
```

原本の URL・SHA256・取得日は `scripts/local-gov/fukuoka-pref/sources.json` に書く。書き出しは手元の PDF の SHA256 が一覧と一致することを確かめ、
違えば止まる（県が資料を差し替えたときに気づくため）。資料を取り直したら一覧を更新する。

OCR は時間がかかる（1ページ約10秒）。手順と設定は [../knowhow/自治体データ調査の手順.md](../knowhow/自治体データ調査の手順.md) の6章。

```bash
# 例: R8 一般会計（PDF 9〜420ページ）を OCR し、読めなかった数字のセルを読み直す（読み直しは2回）
PYLIB=<pylib> python3 -P scripts/local-gov/fukuoka-pref/ocr/ocr_pages.py <dir>/pdf/281298.pdf <dir>/ocr/r8-ippan 9-420
python3 -P scripts/local-gov/fukuoka-pref/ocr/parse_setsumeisho.py <dir>/ocr/r8-ippan 9-420 > parsed.json
PYLIB=<pylib> python3 -P scripts/local-gov/fukuoka-pref/ocr/refill_missing.py <dir>/pdf/281298.pdf <dir>/ocr/r8-ippan parsed.json
```

## 2. 全ステップを流す（回帰テストを兼ねる）

```bash
FUKUOKA_DATA=<dir> python3 -P scripts/local-gov/fukuoka-pref/tests/regression.py --keep <作業ディレクトリ>
```

抽出・検算・突き合わせ・多数決の出力が `<作業ディレクトリ>` に残る。差分が出たら原因を確かめる（テストの運用の決まり）。

## 3. 共通 JSON 形式に書き出す

```bash
python3 -P scripts/local-gov/fukuoka-pref/export_fukuoka_pref.py --work <作業ディレクトリ> --pdf-dir <dir>/pdf \
  --out public/data/local-gov/fukuoka-pref
```

`budget-2026-initial.json`（R8 当初予算。一般会計・特別会計14会計）と `index.json`（資料の URL・SHA256）ができる。

名前は書き出しの中で裏付けを取る（`name_evidence.py`。名前の補正の設計 docs/local-gov/tasks/20261106_1241_名前の補正の設計.md）。
- 全文検索の資料は `sources.json` の `"corpus": true` の PDF（`<dir>/pdf` に置く。SHA256 が違えば止まる）
- 名前の修正表 `ocr/corrections/r8-names.json`（画像で確かめた名前）を当てる。当たる先がない・1件に絞れない修正があれば止まる
- 裏付けのない款・項・目・節の一覧が `<作業ディレクトリ>/names-unresolved.json` に出る（ページ・位置付き）。
  残っていれば、ページ画像の切り抜きで確かめて名前の修正表に足す。要約の「名前の出典」で出典ごとの件数を見る

## 4. 検証

```bash
npm test   # Node.js 22。tests/local-gov-validate.test.ts が書き出したデータをすべて検証する
```
