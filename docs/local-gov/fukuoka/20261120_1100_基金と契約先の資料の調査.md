# 基金と契約先の資料の調査（国版の「基金」「事業者」「委託構造」を福岡県で作れるか）

- 日付: 2026-11-20
- 目的: 国版のタブ「基金」「事業者」「委託構造」に当たるものを福岡県の公開資料で作れるかを確かめる（「評価一覧」は作らない。ユーザー判断）
- 確かめ方: 県のページを読み、実物のファイル（PDF・Excel）を開いて列を確かめた。ファイルは `$D/research/20261120/` に置いた（リポジトリに入れない）

## 1. 結論

| 国版のタブ | 福岡県で | 根拠 |
|---|---|---|
| 基金 | **作れる** | 基金ごとの年度末現在高（33基金）が決算の「財産に関する調書」にテキストで載る。積立金・繰入金は予算書・決算書の目・節にある。複数年の推移は財政状況資料集（Excel）の「基金残高に係る経年分析」 |
| 事業者 | **建設工事なら国版に近いものが作れる**。物品・随意契約は落札者（相手方）と金額だけ。業務委託は案件ごとのページで、参加業者ごとの入札金額・点数が載る案件もある（形は案件ごとに違う） | 建設工事の入札結果（Excel）に予定価格・契約金額・契約者・**入札業者の一覧**（無効・辞退・くじの印つき）がある → 入札者数・1者応札・落札率が数えられる。法人番号はない |
| 委託構造 | **国版の形（事業 → 支出先 → 再委託）は作れない** | 事業と支出先を結ぶ資料・再委託の資料がない。作れるのは「部局・事務所・課 → 契約先」の1段 |

- 建設工事の Excel は県土整備部の1四半期で約 980 行。1者応札・くじ・落札率（契約金額 ÷ 予定価格）が数えられる
- 物品・業務委託は案件ごとのページなので、集めるには一覧のページ（`/life/8/63/277/`。約 330件）から辿る必要がある。業務委託の入札結果表の形は案件ごとに違いうる
- **法人番号がない**ので、事業者の名寄せ（「（株）」の位置・支社名の揺れ）が要る。国税庁の法人番号の公表データで名前と所在地から引く方法がある（未検討）
- 契約と予算の事業（説明書の事項）を結ぶ鍵はない（契約は部局・事務所・課の単位）

## 4. 委託構造

- 国版は RS システム（行政事業レビュー）の「事業 → 支出先 → 再委託先」を使う。福岡県には事業ごとの支出先・再委託の公表がない
  （補助金の交付先も、額つきで公表されているのは国の交付金の実績の1件だけ。[補助金の交付先の公表状況](補助金の交付先の公表状況.md)）
- 作れるのは「部局・事務所・課 → 契約先」（3章の資料）と「施設 → 指定管理者」の1段。国版の委託構造のタブとは別物になるので、
  作るなら「事業者」のタブの中の見方（部局 → 契約先のサンキー図など）にする

## 5. 作るもの（2026-11-20 ユーザー決定）

**基金だけを作る**。事業者・委託構造（と評価一覧）は作らない。
この調査の結果（事業者は建設工事のほかは案件ごとのページで形が揃わず、契約と予算の事業を結ぶ鍵もない。委託構造は事業 → 支出先 → 再委託の資料がない）を
見たうえでのユーザー判断。基金は資料が揃い量も少ない（R6 決算の残高＋R8 予算の積立・取崩し。過年度をさかのぼって推移）。
基金の設計と実装は `docs/local-gov/tasks/20261120_1200_地方版の基金の設計.md`（基金の PR で足す）。
