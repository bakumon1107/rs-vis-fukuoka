## 1. OGP 画像の URL に版がない

- 見つけ方: `/code-review`（`main` の最新のコミット 92721f7 を対象）の指摘を、コードで確かめた
- レビューの提案（`socialImagePath` に `?v=` を足す）は、そのままでは**生成スクリプトが壊れる**: `scripts/generate-social-images.ts` は
  `socialImagePath` を保存先のファイルの場所にも使っている。また `app/lp/page.tsx` は `/og/home.png` を直書きしていて `socialImagePath` を通らない
- 直し方: `socialImagePath`（ファイルの場所）はそのまま、URL 用の `socialImageUrl`（`?v=${SOCIAL_IMAGE_VERSION}`）を足して
  `pageMetadata` と `/lp` で使う。画像を作り直したら `SOCIAL_IMAGE_VERSION` を上げる（生成スクリプトに記載）
- 確認: 単体テスト（`tests/page-metadata.test.ts`、全ページ）、typecheck・lint、開発サーバーで `/`・`/lp`・`/budget-sankey` の `og:image` が
  `?v=2` 付きで画像も返ること。e2e（`tests/e2e/public-ux.spec.ts`）は URL のパスだけを比べているので変更不要
- 地方版の対策: [tasks/20261106_0111_地方版予算ビュー全体計画.md](tasks/20261106_0111_地方版予算ビュー全体計画.md) 5章（OGP の URL に版を付ける）

## 2. OGP 画像のフォントが作り直す環境で変わる

- 見つけ方: `/code-review`（`main` の 92721f7 を対象。2026-11-07）の指摘を、コードで確かめた（サイト本体は `app/layout.tsx` で
  `next/font` の Noto Sans JP を使うのに、画像のテンプレートは `'Yu Gothic',Meiryo,sans-serif`）
- 直し方: テンプレートで Google Fonts の Noto Sans JP（サイトと同じ）を読んで最初に指定し、読めなかったら画像を書き出さずに止める。
  Google Fonts は字の範囲（unicode-range）ごとにファイルを分けるので、**画像に描く字すべてと、使う太さ（400・700）ごとに**確かめる:
  `document.fonts.load(フォント, 描く字)` が 0 件（スタイルシートが読めない。このとき `check()` は true を返すので `check()` だけでは止まらない）・
  `load()` が例外・`check(フォント, 描く字)` が false（一部の範囲のファイルが読めない）のどれかで止める。
  2026-11-07 の /code-review で2回指摘され（`check()` だけ → `load()` の件数だけでは、既定の字（空白）の範囲・太さ 700 しか見ていなかった）、
  そのたびにコミットを直して置き換えた。画像は作り直していない（作り直すと見た目が変わるので、#1 の URL の版を上げる修正と合わせて作り直すのがよい）
- 限界: Google Fonts が配るフォントの版は固定できないので、Google 側でフォントが更新されると描画が変わりうる（環境による違いはなくなる）。
  完全に固定するなら、フォントのファイルをリポジトリに置いて読む
- 確認: headless Chromium で、通常は通る（400・700 とも `load()` 15 件・`check()` true）、Google Fonts への通信を止めると止まる
  （`load()` 0 件・`check()` true）、フォントのファイルを1つおきに落とすと止まる（`load()` が NetworkError・`check()` false）ことを確認。
  型チェックで今回の変更にエラーなし

## 3. OGP 画像のテンプレートの使っていない CSS

- 見つけ方: 同じ `/code-review` の指摘を、コードで確かめた（見出しの中は製品名の `<span>` だけ）
- 直し方: `header svg{width:190px;height:36px}` と `gap:28px` を外す
- 確認: 外す前後で同じ内容を描き、画素が一致することを確認（描画は変わらない）

## 4. OGP 画像の見出し・説明文が語の途中で折り返される

- 見つけ方: `/code-review`（`main` の 92721f7。2026-11-07）の指摘を、同じ説明文を描いて確かめた
- 直し方: 見出し（h1）と説明文（p）に `word-break: auto-phrase`（Chromium が日本語を文節で区切る）。画像は Playwright の Chromium で
  作るので、依存を足さずに使える。画像は作り直していない（#1 と合わせて作り直す）
- 確認: 指定ありで「…チームみらいの／政府予算ビュー。」「…流れを／ひとつながりで追う」と文節の切れ目で改行することを確認

## 5. OGP 画像の生成でページの指定が当たらないと正常終了する

- 見つけ方: 同じ `/code-review` の指摘を、コードで確かめた（`SHARE_PAGES.filter(...)` が空でもそのまま終わる）
- 直し方: ページを指定して当たらなければ、指定できるページの一覧を添えてエラーにする（ブラウザを起動する前に確かめる）
- 確認: 先頭の / なし（`budget-sankey`）で実行するとエラーで止まることを確認。typecheck エラーなし
