## 1. OGP 画像の URL に版がない

- 見つけ方: `/code-review`（`main` の最新のコミット 92721f7 を対象）の指摘を、コードで確かめた
- レビューの提案（`socialImagePath` に `?v=` を足す）は、そのままでは**生成スクリプトが壊れる**: `scripts/generate-social-images.ts` は
  `socialImagePath` を保存先のファイルの場所にも使っている。また `app/lp/page.tsx` は `/og/home.png` を直書きしていて `socialImagePath` を通らない
- 直し方: `socialImagePath`（ファイルの場所）はそのまま、URL 用の `socialImageUrl`（`?v=${SOCIAL_IMAGE_VERSION}`）を足して
  `pageMetadata` と `/lp` で使う。画像を作り直したら `SOCIAL_IMAGE_VERSION` を上げる（生成スクリプトに記載）
- 確認: 単体テスト（`tests/page-metadata.test.ts`、全ページ）、typecheck・lint、開発サーバーで `/`・`/lp`・`/budget-sankey` の `og:image` が
  `?v=2` 付きで画像も返ること。e2e（`tests/e2e/public-ux.spec.ts`）は URL のパスだけを比べているので変更不要
- 地方版の対策: [tasks/20261106_0111_地方版予算ビュー全体計画.md](tasks/20261106_0111_地方版予算ビュー全体計画.md) 5章（OGP の URL に版を付ける）
