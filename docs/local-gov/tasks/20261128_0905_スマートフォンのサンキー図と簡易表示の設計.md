# スマートフォンのサンキー図（縦・横）と簡易表示の設計

2026-11-28。ユーザーの依頼:

- スマートフォンの横向きに対応してほしい（横幅は広がるのに見づらい）
- 縦向きで、一番右の列の金額が隠れるのをどうにかしたい
- 小諸市の「まるっと予算ナビ」（https://thunder-19900512.github.io/komoro-budget/#flow）のような簡易表示も検討

## 1. 今の様子（公開中のサイトを 390×844・844×390 で撮って確かめた）

| 向き | 判定 | 描き方 | 困りごと |
|------|------|--------|----------|
| 縦（390px） | `useIsNarrow`（640px 未満） | 選んだ列を真ん中にした3列。名前は6字まで、**金額は出さない**（`NARROW.showAmount=false`） | 金額が一切見えない。右の列の名前が「市町村地域…」のように切れる |
| 横（844px） | 640px 以上なので**パソコンと同じ** | 財源・款・項の全部の列、名前18字・金額つき | 図の高さが 1410px（項 60 個 × 1行 18px）で、画面の高さ 390px に対して縦に長すぎ、全体が一度に見えない。款の金額のラベル（「総務費 829.08億円」）が項へ行く帯の上に重なる |

小諸市の図は、縦向きでは図を 660px の幅で描いて横にスクロールさせ（「図は横にスクロールできます →」）、
名前の下の2行目に金額を出している。列は 歳入の款 → 財源の性質（一般財源・国県の補助金など・市債・その他）→ 歳出の款 の3列だけで、
高さは固定（560px）。

## 2. 変えること（案）

### 2.1 横向き: 「中くらい」の描き方を足す

- **判定**: 幅 640px 以上でも、**画面の高さが 500px 未満**（`(max-height: 499px)`。スマートフォンの横向き）なら中くらいにする
- **描き方**: 縦向きと同じく **3列**（選んだ列を真ん中に。`windowColumns`）。ただし幅があるので、**名前は10字・金額つき**
- 列の間が広くなるので、金額のラベルが次の列の帯に重なりにくい

### 2.2 縦向き: 金額を名前の下の2行目に出す

- 3列のまま、**箱のラベルを2行**（1行目: 名前、2行目: 小さい字で金額「829.08億円」）にする。横に並べないので、余白の幅は今とほぼ同じで足りる
- 1行の高さ（`minNodeSlot`）を 18px → 26px にする（2行が重ならないように）。図は縦に少し長くなる
- 名前の上限は今の6字のまま（2行目に金額が入るので幅は増やさない）。右の列の名前が切れるのは変わらないが、押すと下に詳細が出るので、そこで全部読める
- 補正後予算の増減の印（緑の「+67.5億」など）も、2行目の金額の後ろに出す（今は縦向きでは出していない）

**別案**（採らない）: 小諸市のように図を横にスクロールさせる。金額は全部見えるが、図の右側を見るには横に動かす必要があり、
選んだ列を真ん中にする今の作りと合わない。

### 2.3 簡易表示（「かんたん」と「くわしく」の切り替え）

図の上に「かんたん／くわしく」の切り替えを置く。くわしく = 今の図。かんたん = 列を減らし、**全部の箱の名前と金額が1画面に収まる図**。

かんたんの図の列の候補:

- **案A（推計なし）**: 財源（国庫支出金・地方債・その他・一般財源）→ 歳出の款（14 前後）の **2列**。今の図の左2列と同じ数字で、推計しない。
  高さは固定（款が 14 個なので、1行 26px でも 400px ほど）で、スマートフォンの縦でも全部入る
- **案B（小諸市と同じ3列）**: 歳入の款（県税・地方交付税・国庫支出金・県債…）→ 財源の性質 → 歳出の款。歳入の款と財源の間の帯は
  資料に載っていないので**推計になる**（小諸市は点線で「差額から推計した流れ」と書いている）。このサイトの「推計しない」方針と合わないので、
  採るならユーザーの判断が要る

かんたんの図の下には、小諸市の「金額の大きい事業」のような **款の一覧（金額の大きい順・帯の長さつき）** を置くとよい（押すとくわしくのその款へ）。
小諸市の上のカード（総額・前年度比・1人あたり）は今回は入れない（必要なら別に）。

**既定**: スマートフォンでは最初にかんたん、パソコンではくわしく（切り替えは URL の `mode=simple` に残す）。

## 2.4 決まったこと（2026-11-28 ユーザー了承「それでいいよ」）と、作りながら決めたこと

- 2.1・2.2 はこの形。簡易表示は案A。#23 は CodeRabbit を待たずにマージしてから作る
- **横向きの判定**は `(min-width: 640px) and (max-height: 499px)`。3列にする判定には指（`pointer: coarse`）の条件は付けない
  （パソコンの高さの低いウィンドウでも3列の方が見やすい）。ただし**最初にかんたんを出す**のは、縦のスマートフォンと、
  横で指で操作する画面だけ（パソコンの低いウィンドウで、開いたらかんたんになっていると驚く）
- 縦向きで増減を出すとき（補正後の見方）は、箱1つの最低の高さを 28px → 38px に上げる（3行のラベルが隣の箱と重ならないように）
- **公営企業会計の見方にはかんたんを出さない**（右の列の会計・条は金額を出さない列で、かんたんの図にならない）
- **縦向きの2行目の金額は短い形**（「845.7億円」。億は小数1桁）。小数2桁だと真ん中の列の金額が右の列の箱に重なる。
  正確な額はツールチップ・選択中の行・詳細で見る
- 縦向きで真ん中の列の箱は、増減の印を**3行目**に出す（2行目に並べると右の列の箱に重なる）
- **かんたんの図は見方の左2列**（一般会計: 財源 → 款、全会計: 歳入の款 → 会計、決算: 部局 → 款／会計 → 款）。
  図の下の一覧は右の列（款・会計など）の金額の大きい順
- 既定: URL に `mode` がなく、スマートフォン（縦・横）で何も選んでいないときはかんたん。かんたんの図・一覧で押すと `mode=detail` でその箱を選ぶ。
  くわしくで選びを外してもかんたんに戻らないよう、既定と違う見え方になるときは `mode` を URL に残す
