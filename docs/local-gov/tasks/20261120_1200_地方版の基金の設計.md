# 地方版の基金の設計（福岡県）

- 状態: **確定（2026-11-20 ユーザー承認）**。決めたことは 7章
- 前提: 国版のタブのうち地方版に足すのは基金だけ（2026-11-20 ユーザー決定）。資料の調査は
  [基金と契約先の資料の調査](../fukuoka/20261120_1100_基金と契約先の資料の調査.md)

## 1. 何が見えるようにするか

- 県の基金（特定の目的のために積み立てたお金）ごとに、**いくら残っているか・その年度にいくら積み立て、いくら取り崩す予定か**
- 財政調整基金（貯金）・減債基金（借金の返済の備え）が大きく、ほかの目的の基金がどれだけあるか。宿泊税・森林環境税・産業廃棄物税など、
  **税を積み立てて使う基金**の出入り
- 国版の基金のタブの「国庫返納」「府省の点検結果」に当たるものはない（県に同じ仕組みがない）

## 3. データ（書き出し）

- 決算のファイル（`settlement-2024.json`）に `funds` を足す（7章）。1件:
  `{ name, kind: "積立" | "運用", balance: {start, change, end, after_closing}, holdings: [{kind: "現金"|"有価証券"|"貸付金"…, end, after_closing}],
  history: [{year, end, after_closing}], source }`
- 推移（`history`）は H23〜R6 の調書から。基金の名前は年度で変わりうる（廃止・新設・改称）。名前で年度をつなぎ、つながらないものは一覧に出して止める（改称は対応表で）
- 予算・決算の出入りは、名前で基金に結ぶ（「〇〇基金繰入金」「〇〇基金積立金」から「〇〇基金」を取り出す）。結べないものは一覧に出して止める
- 検算: 前年度末 + 増減 = 年度末（基金ごと・区分ごと）。調書の基金の合計と、附属明細書の「基金の明細」・財政状況資料集の基金残高（百万円）を突き合わせる
- 金額は1円単位で書き出す（調書は千円）

## 4. 画面（案）

- 場所: **別のページ `/local/[gov]/funds`**（実装で変えた。2026-11-20）。残高は決算のファイル、積み立て・取り崩しは当初予算のファイルで、
  読むデータが2つになるので、サンキー図の見方の切り替えにせずページを分けた。サンキー図のページの見出しの横に「基金」へのリンク、基金のページにサンキー図へのリンク
- 推移の図: 年度ごとに財政調整基金・減債基金・その他を積み上げた棒（H22〜R6 の年度末。OCR の年度に印）
- 一覧の表: 基金ごとに R6 年度末の残高・R8 の取り崩し予定・R8 の積み立て予定・差し引き。残高の多い順。目的（基金の条例の名前から）
- 図: 残高の大きさの横棒（財政調整・減債が大きいので、対数でなく「大きい2つ／その他」を分けて見せる）
- 詳細: 基金を押すと、残高の内訳（現金・有価証券・一般会計への貸付）、積み立て・取り崩しの元の予算の目（サンキー図のその目へ）
- 注意書き: 残高は R6 年度末（決算）、出入りは R8 予算（予定）で、**時点が違う**。R8 年度末の残高の見込みは作らない（推計しない）

## 5. 範囲外

- 県が出資した財団（「公益財団法人 福岡県スポーツ推進基金」など。財産に関する調書の「出資による権利」）は県の基金ではない。載せない
- 公営企業会計の積立金
- 基金の運用益の内訳

## 6.5 実装の結果（2026-11-20）

- 調書の 14 年分のうち、テキストは H23・H25・H30・R2・R5・R6。画像は OCR（`ocr/ocr_lines.py`）で H27・H28・H29・R4 を全部、
  H24・R3 は「補助の年度」（その年度の間に廃止した基金だけ。OCR の質が低く、ほかの基金は次の年度の調書の前年度末で足りる）。
  H22・H26・R1 の年度末は次の年度の前年度末。推移は H22〜R6 末の 15年
- 検算: 区分ごとに 前年度末 + 増減 = 年度末・年度末 + 出納整理 = 出納閉鎖日。続く年度の 前の年度末 = 後の前年度末（区分ごとと基金の合計の両方。
  区分の行が落ちると区分ごとの比較だけでは気づけない）。区分の名前があるのに額として読めない行・区分の分からない額の行は FAIL
- OCR の直し（どれも検算で1通りに決まるときだけ。回帰テストの要約に記録）: ▲ の読み落とし（符号）・「▲」を「7」と読んだ行（H29 減債基金の現金。
  直す前は現金の行が黙って落ち、H29 末の合計が 540億円 小さかった）・0 を1つ落とした「0 0 0 0」の行・簡体字などの名前の崩れ（テキストの年度の名前に寄せる）
- 改称: こども育成基金 → 出産・子育て安心基金（R5）、緊急経済対策資金信用保証料補填臨時基金 → …資金等…（R4）。前の年度末と後の前年度末の一致で確かめた
- 自己レビュー（/code-review）の指摘 10件をすべて直した（上の検算の強化・予算の結び付けの漏れ・名前の短縮「県営」「県立」・令和元年度 など）
- CodeRabbit の指摘（PR #12）で改めた扱い（読み取れない値をこしらえない）:
  - 区分の行だけで額のない基金（OCR は「－」を読まない）は、原本の画像で全部「－」と確かめた年度・基金（`NO_FIGURES_CONFIRMED`。
    県営林造成事業振興基金の H27・H28・H29・R4）だけ 0 にする。それ以外は額の行の読み落としと区別できないので FAIL
  - 区分の名前を読んだのに額の行が入らなかった区分は FAIL（次の基金に移って黙って落ちない）
  - OCR の名前は、字形の表（簡体字・異体字・「·」）と確かめた名前の表（`OCR_NAME_FIXES`。小書きの「ャ」）だけで直す。似ているだけの名前には寄せない
    （別の基金でも額の検算は通るため）。表にない名前は FAIL にし、似た名前を候補として出す
  - OCR の作業ディレクトリは、範囲のページがそろった印（`done.json`）があるものだけ読む（途中で止まった OCR で一部の基金だけの年度にしない）
  - 抽出の検算の失敗は funds.json の `fails` に書き、書き出し（export_funds）が止まる（終了コードを見ない使い方でも決算のファイルに入れない）
  - 財政状況資料集・附属明細書との違いは「定義が違う」と言い切らず、一致しないこと（R6 で確認）と、理由は未確認であることを書く

## 7. 決めたこと（2026-11-20 ユーザー承認）

1. **見せる時点**: R6 決算の残高＋R8 予算の出入り＋**残高の推移（H23〜R6 の 14年）**
2. **ファイル**: 決算のファイル（`settlement-2024.json`）に `funds` を足す
3. **財政調整基金特別会計**（任された。方針）: 出入りは**一般会計との境目だけ**で数える。積み立ては一般会計の「財政調整基金特別会計繰出金」、
   取り崩しは一般会計の「財政調整基金繰入金」。特別会計の中のやり取り（特別会計の歳入・歳出）は数えない（二重になる）。
   残高は調書の財政調整基金（現金と一般会計への貸付を分けて）。ほかの基金で特別会計を通るもの（市町村振興基金特別会計）も同じ扱い
4. **順番**: 基金を先に終わらせる（バブル図はその後）。ブランチ `feat/fukuoka-funds`（local-main から）
