## 2. A: 全会計の純計

- 全会計の見方の見出しの総計の横に、「純計 3兆224億円（会計間の繰入れ 2,955億円を除く。このサイトの計算）」を出す。図の帯は変えない
- 計算: 全会計（一般会計＋特別会計14）の総計 − 会計間の繰入れ。繰入れは歳入の目の `transfer` の印（R8 当初で15件）。
  出し手の歳出（節「繰出金」。R8 は節 27）の合計と受け手の歳入の合計が千円の位まで一致することは確かめた（純計の下調べ 4章）。
  **作った形（2026-11-27）**: 画面が正規化データの印から計算する（`app/lib/local-gov/totals.ts` の `netTotal`。補正後の見方でも同じ計算）。
  書き出し（`export_fukuoka_pref.py`）は、受け手の印の合計 = 出し手の節「繰出金」の合計（名前で数える。番号は年度で変わる）を検算し、
  違えば止める。補正の書き出しは、補正で会計間の繰入れ・繰出金が動いたら止める（R8 の補正にはない。動いたら補正にも印と検算を足す）。
  正規化データには純計を持たない（印から決まるので二重に持たない）
- 県の資料に純計の数字はない（照合先がない）ので、「このサイトの計算」と書く
- 補正後の見方: 補正の繰入れも同じ印で数えられるので出す。決算: 決算のファイルには繰入れの印がないので出さない（R6 決算は対象外）
- 公営企業会計は全会計の見方に入れない（4章）ので、純計にも入れない（今の総計と同じ範囲）

## 3. B: 人件費の割合（詳細）・C: 基金の注記

**B**: 款・項・目・会計を選んだときの「選択中」の行に「うち人件費 ○○円（○%。節の報酬・給料・職員手当等・共済費の合計）」を出す
（作った形。事項・節を選んだときは出さない: 絞り込みは目までなので、目全体の額になる。予備費の目は節を持たないので人件費 0 として数え、
ほかに節のない目を含む範囲では出さない）。
節の額を足すだけで推計しない。目は説明書の節、款・項はその下の目の節の合計。R8 の一般会計では 4,388億円（歳出の 19%）、
警察費 84%・教育費 63%・議会費 55%。決算（R6）も節があるので同じに出す。純粋な関数（`app/lib/local-gov/`）にしてテストする

令和7年度の残高は令和7年度決算（例年12月ごろ公表）で更新します」）。表の列見出しにも年度を入れたまま。R7 決算が出たら、調書を取り込み残高を R7 末に上げる

## 4. D: 公営企業会計

### 4.1 資料と今の抽出

- 資料: 特別会計の予算に関する説明書（R8 `281299.pdf`）の後半の「予算実施計画」。5会計（病院事業・流域下水道事業・電気事業・
  工業用水道事業・工業用地造成事業）、収益的収入及び支出（第3条）・資本的収入及び支出（第4条）の 款 → 項 → 目（千円）
- 抽出 `extract_kigyo_jisshi.py` は済み（回帰テストのステップ「公営企業 予算実施計画」）。目 74 件。**額は予算書の本体の第3条・第4条と
  完全に一致する**（目 → 項 → 款の合計も一致。FAIL 0）
- **名前が崩れている**: 発行元が付けた文字層そのものの読み誤り（「建設改良費」→「建云比又几改良費」、「受託運転益」→「乎又託運転益」、
  「医業収益」→「区業収益」など）。異なる名前 88 のうち約 20
- R8 の支出は5会計で約 476億円（第3条 257億・第4条 219億）。流域下水道がいちばん大きい（第3条 199億・第4条 149億）
- R8 の補正予算（4回）に公営企業会計の分はない。R6 決算の公営企業会計は取り込んでいない（決算の見方には出さない）

### 4.2 名前の直し

一般会計と同じ考え方（複数の読み取り＋画像で確かめた修正表）で、名前に出典の印（`name_src`）を付ける:

1. 実施計画のページ（R8 で 17ページ: 病院 p134〜138・流域下水道 p164〜167・電気 p202〜204・工業用水道 p236〜238・工業用地造成 p270〜271）を、新 OCR（PP-OCRv6）と NDLOCR-Lite で読み、款・項・目の名前の欄の読みを集める
   （額は文字層で照合済みなので、名前だけを読む。行の位置は文字層の行に合わせる）
2. 文字層・新 OCR・NDLOCR-Lite の3つの読みのうち2つ以上が一致すればそれを使う（`readings`）。一致しないものは画像で確かめて
   修正表に足す（`correction`。確かめたページを書く）
3. 公営企業会計の科目名は会計の種類ごとにほぼ決まっている（地方公営企業法施行規則の別表の款・項・目。「医業収益」「入院収益」
   「営業費用」「減価償却費」「建設改良費」「企業債償還金」…）。決まった名前の一覧に近い名前を**候補**として出すが、寄せるのは画像で確かめたものだけ
4. 書き出しは、裏付けのない名前（読み取りが1つだけで画像で確かめていない）が残れば止める

**作った形（2026-11-27）**（上の案から変えた点）: `kigyo_names.py`（回帰テストのステップ「公営企業 名前」）
- 読みは **文字層・新 OCR（`ocr/ocr_lines.py` の行。17ページ）・予算書の本体（款・項だけ。発行元の本物の文字）** の3つ。
  NDLOCR-Lite は使わない（道具が説明書の表の作りを前提にしていて、実施計画の表に合わない。17ページなので全部を画像で見る方を取った）
- 文字層の名前が新 OCR の同じページの文字に含まれる（簡体字をそろえて比べる）か、予算書の本体の款・項と同じなら `readings`。
  修正表（`ocr/corrections/r8-kigyo-names.json`）にあれば `correction`。どちらでもなければ止める。修正表の行が使われなければ止める
- 「含まれる」は、途中で切れた・字の欠けた名前も一致に見える（「償還元金」の行に「償還金」が含まれる）。語どうしの一致にすると、
  新 OCR が1字ずつ空けて読む名前（「予 備 費」）が割れて 73件が不一致になり使えない。そこで **R8 は17ページすべての名前を画像で見比べ**、
  そうしたものも修正表に入れた（名前の区切りの誤り「管渠・ポンプ場．」「処理場費業務費」→「管渠・ポンプ場・処理場費」「業務費」、
  字の欠け「償還金」→「償還元金」）
- 結果: 款・項・目 140 のうち 2つの読みが一致 114・修正表 26（文字層の崩れ 25、文字層が正しいが新 OCR が読み落とした 1「減価償却費」）
- 補填財源: 予算書の本体（議案）の第4条の文言を `extract_yosansho.py` で読む（5会計とも 内訳の合計 = 不足額 = 支出 − 収入。FAIL 0）

### 4.3 正規化データ（当初予算のファイルに足す）

- `accounts` に `enterprise:<slug>`（`kind: 'enterprise'`）を5つ足す（型は既にある）
- `rows` に目の行を足す: `side` は収入 = revenue・支出 = expense、`enterprise_section` は 収益的（第3条）・資本的（第4条）、
  ID は `enterprise:<slug>/<side>/<条>-<款>-<項>-<目>`（款の番号が条ごとに振り直されるため、条を ID に入れる）。
  額は `src: 'text'`（発行元の文字層。予算書の本体と照合済み）
- 会計ごとに `enterprise` の付表を持つ:
  - `capital_shortfall`: 資本的収入が資本的支出に足りない額と、その補填財源の内訳（予算書の本体の第4条の文言から読む。
    例: 流域下水道 1,801,100千円 = 当年度分消費税及び地方消費税資本的収支調整額 18,245 + 過年度分損益勘定留保資金 259,908 +
    当年度分損益勘定留保資金 1,522,947）。**内訳の合計 = 資本的支出 − 資本的収入** を検算し、合わなければ止める
  - 収益的収支の差（収入 − 支出。予算上の利益・不足）。足し算で決まる額
- 一般会計からの負担金・補助（病院事業の「一般会計負担金」など）は、収入の目に印を付ける（会計間の重なり。4.4 の注記に使う）。
  一般会計の歳出のどの目と対になるかは書き出しのときに確かめる（対が決まらなければ印だけにして、画面で「一般会計からの分を含む」と書く）
- 一般会計・特別会計だけを前提にしている確かめ（検算の行数・全会計の総計・純計）は、`kind: 'enterprise'` を外して数える（今もそうなっているかを確かめる）

### 4.4 画面: 公営企業会計の見方

当初予算の見方に「公営企業会計」を足す（一般会計・全会計と並べる）。決算・補正後には出さない（データがない）。

```
収入の項 ──→ 会計・条 ──→ 支出の項 ──→ 目
（入院収益…）  （流域下水道 収益的）  （営業費用…）
補填財源の内訳 ─→ （○○ 資本的）
                  （○○ 収益的）──→ 収益的収支の差（予算上の利益）
```

- 真ん中の列は「会計 × 条」の箱（5会計 × 2 = 10）。左に収入の項、右に支出の項 → 目
- 資本的収支の不足は、左に「補填財源（過年度分損益勘定留保資金など）」の箱で入れる（4.3 の内訳。予算書の数字なので推計ではない）
- 収益的収支で収入が支出より多い会計は、差を右に「収益的収支の差（予算上の利益）」の箱で出す。支出の方が多い会計（R8 では工業用地造成）は、
  差を左に「収益的収支の不足」の箱で入れる。どちらも足し算で決まる額
- これで、真ん中の箱の入り = 出がどの箱でも成り立つ（テストで確かめる。今の全会計の見方と同じ検算）
- 見出しに5会計の支出の合計（第3条・第4条の別）を出す。注記: 「収益的収支（毎年の営業）と資本的収支（施設の建設・借金の返済）に分かれます。
  資本的収支の不足は、会計の中に留保した資金などで埋めます（予算書の第4条）。一般会計からの負担金を含みます（全会計の見方と重なる）」
- 全会計の見方は今のまま公営企業会計を描かず、「公営企業会計は含みません」の注記から公営企業会計の見方へのリンクを出す
- 詳細のパネル: 目を選ぶと、会計・条・款・項・目の名前と額、名前の出典の印（読み取り・画像で確かめた）、出典のページ。
  公営企業会計の目には説明欄・財源内訳・節がない（実施計画は目まで）ので、その欄は出さない

### 4.5 検算・テスト

- 抽出: 目 → 項 → 款の合計、款・項 = 予算書の本体（今ある）。補填財源の内訳の合計 = 不足額（新しく足す）
- 書き出し: 名前の出典がすべて付いていること。会計ごとの第3条・第4条の収入・支出の合計が予算書の本体と一致すること
- グラフ（純粋な関数）: 公営企業会計の見方で、真ん中の箱の入り = 出、各列の合計、0 円の帯を作らない、収益的の差・補填財源の箱の額
- 回帰テスト: 書き出しの要約に公営企業会計の行（会計数・目の数・名前の出典の内訳）を足す
