# 補正後予算の当初からの増減の表示の設計

作成: 2026-11-27。状態: 設計（ユーザー確認待ち）

## 1. 目的

補正後予算の見方で、**当初予算から各項目（会計・款・項・目）がどれだけ増減したか**を見えるようにする。

ユーザーの決定（2026-11-27）:

- 「簡単（図のラベルと見出し）」と「詳しく（増減の表）」の**両方を入れる**
- 見出しに「当初から」などを書くと長くなるので、**見出し・ラベルの言葉は短く**する

## 2. 今あるもの

- 補正後（`basis=latest`）は画面で当初 + Σ補正を組み立てる（`app/lib/local-gov/supplement.ts` の `composeLatest`）。
  各目の行に `before`（当初の額）・`amount`（補正後の額）・`supplements`（回ごとの補正額。古い順）・`added_in`（補正で新設した目）がある
- 目の詳細パネルには、補正後・当初・回ごとの補正額が出ている（`LocalDetailPanel` の latestAmounts）
- 図（サンキー図）は補正後の額で描いている。**増減は図のどこにも出ていない**
- R8 の補正は 4 回（6月・8月専決・9月・9月追加）

## 3. 増減の求め方（純粋関数）

新規 `app/lib/local-gov/supplement-diff.ts`。

- **箱の当初の額**: 同じ見方・同じ深さ・同じ絞り込みで、**当初のファイルからも図を組み立て**、箱の ID で対応させる（箱の ID は会計・款・項・目の番号と目の行の ID で決まるので、当初と補正後で同じ）。
  当初の図にない箱（補正で新設した目とその上の箱）は当初 0
  - 財源の列（一般会計の見方の左端）: 当初の図の財源の箱の額と比べる。財源内訳を足し合わせられなかった目は補正後の図で「財源の記載なし」に回るので、
    財源の箱の増減は「財源内訳の分かる範囲」になる。財源の箱には増減を出さない（誤解を招く）案を推す（6章）
- **増減** = 補正後の箱の額 − 当初の箱の額（円の整数。推計なし）
- **表の行**: 補正後のファイルの目の行（`before`・`amount`・`supplements`）を 会計 → 款 → 項 → 目 に足し上げる。
  回ごとの補正額も足し上げる（どの回で増えたかが分かる）
- 当初のファイルは `useLocalBudget` が補正後を組み立てるときに読んでいるので、状態に一緒に持たせる（読み直さない）

## 4. 画面

### 4.1 簡単: 図のラベルと見出し（短く）

- **見出し**: 今の「補正後予算（9月補正まで）」の後ろの額の並びに、**「補正 +○○億円」**だけを足す（「当初から」は書かない）。
  例: `一般会計の歳出 ○.○○兆円（補正 +○○億円）`
- **図の箱のラベル**: 額の後ろに増減を小さく、色を付けて添える。**増えた箱は「+12.3億」（緑）、減った箱は「△4.5億」（赤）、増減のない箱は何も付けない**。
  単位は「億」「万」を短く（「億円」の「円」を省く）。補正で新設した目は「新」の印
  - ラベルが長くなって隣の列に重なるのを避けるため、**増減の印は 1 万円未満の端数を落とした短い形**にし、真ん中の列（公営企業会計の会計・条など、金額を出さない列）には出さない
- **選択中の行**: 箱を選んだら「当初 ○○ → 補正後 ○○（+○○）」を出す（今の人件費の行と同じ場所）
- 当初予算・決算の見方では何も変わらない

### 4.2 詳しく: 増減の表

- 補正後の見方のとき、図の下に**「補正の増減」の表**を出す（折りたたみ。最初は閉じる。開くと表）
- 行: 会計（全会計の見方）／款 → 項 → 目。押すと下の段を開く（基金の表と同じ開き方）
- 列（広い画面）: 名前・当初・6月・8月専決・9月・9月追加（回ごとの補正額。回の数はデータから）・補正後・増減
- 列（スマートフォン）: 名前・当初・増減・補正後（回ごとの額は行を開くと出す）
- 並べ替え: **増減の大きい順（絶対値）**を既定にし、「款の順」に切り替えられる
- 増減 0 の行は既定で隠す（「増減のない項目も表示」で出す）
- 目の名前を押すと、図でその目を選んだ状態にする（`?sel=moku:...`）

## 5. 検算・テスト

- 増減の合計 = 補正のファイルの総括の補正額の合計（会計ごと・歳入歳出ごと。今の補正の書き出しの照合と同じ値）
- 箱の当初の額 = 当初の見方の同じ箱の額（当初のファイルから組み立てたグラフと一致）
- 表の行の足し上げ: 目の当初・補正後・回ごとの額の合計 = 款・項の値
- 補正で新設した目（R8 8月専決「県議会議員補欠選挙費」など）は当初 0・「新」の印
- R8 の実データでテスト（4 回分）

## 6. 決めてほしいこと

**決定（2026-11-27 ユーザー）**: 1 は出さない（財源の箱には増減を付けない）。2 は図の下に折りたたみ。3 は歳入も表に入れる。

1. 財源の箱（一般会計の見方の左端）にも増減を出すか（推奨: 出さない。財源内訳を足し合わせられない目があり、増減が財源の実際と合わないことがあるため）
2. 増減の表の置き場所: 図の下に折りたたみ（推奨）／別のページ（`/local/fukuoka-pref/supplement`）
3. 歳入（全会計の見方の左端の歳入の款）の増減も表に入れるか（推奨: 入れる。補正の財源が分かる）
