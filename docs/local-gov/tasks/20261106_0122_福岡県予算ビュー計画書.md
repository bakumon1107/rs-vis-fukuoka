## 1. 目的

福岡県が公開している既存データだけを使って、県予算の流れを可視化する。
国版の「会計 → 所管 → 項 → 目 → 事業 → 支出先」に相当するものを、県の予算書の構造
「**会計 → 款 → 項 → 目 → 事項（説明欄）**」で再現する。行政評価・契約情報は事項や部局に結び付ける付加情報とする。

### 2.2 予算に関する説明書（A・B）の構造

**全体構成（R8 一般会計、目次で確認）**

| 部 | 印字ページ | 内容 |
|---|---|---|
| 第1 歳入歳出予算事項別明細書 | 1〜412 | 1 総括（3〜）、2 歳入（7〜112、15款）、3 歳出（113〜412、14款） |
| 第2 給与費明細書 | 413〜 | 職員数・給与の内訳 |
| 第3 債務負担行為の調書 | 437〜 | 翌年度以降の支出予定 |
| 第4 地方債の調書 | 469〜 | 県債の残高見込み |
| 特別会計（B） | 475〜600 | 総括＋14特別会計（一般会計と同じ様式） |
| 公営企業会計（B） | 601〜770 | 病院・流域下水道・電気・工業用水道・工業用地造成（公営企業の様式） |

- PDF のページ番号と印字ページのずれ: 一般会計は「PDF ページ = 印字ページ + 8」（目次などの分）。款の扉ページと白紙ページが挟まる。
- 歳出の款の扉（例: 印字121「(2) 総務費」）、白紙（印字122）、本文（印字123〜）の順。

**歳出ページの表（印字123・192で確認）**

| 列 | 内容 |
|---|---|
| 見出し | 「2款 総務費」「1項 総務管理費」（款・項は表の上の見出し） |
| 目 | 番号と名称（例: 1 一般管理費） |
| 本年度・前年度・比較 | 千円 |
| 本年度の財源内訳 | 特定財源（国庫支出金・地方債・その他〔使用料及び手数料・財産収入・諸収入 など〕）と一般財源 |
| 節（細節） | 区分（1 報酬・2 給料・3 職員手当等 … 18 負担金補助及び交付金・24 積立金 など）と金額。細節（扶養手当など）は枠で囲まれる |
| 説明 | **「○事項名 金額」の列挙**（例: ○職員費 293人 2,459,659、○管理事務費 2,960,581 …） |

**金額の整合を手で確認した結果（2例）**

- 2款1項1目 一般管理費: 本年度 17,854,435 ＝ 説明欄12事項の合計 ＝ 財源内訳の合計（国庫 136,495＋地方債 6,782,800＋その他 531,108＋一般財源 10,404,032）。**完全に一致**
- 3款（保健費）の 2目 国民健康保険連絡調整費: 本年度 47,713,092 ＝ 説明欄5事項の合計。**一致**

→ **説明欄は目の全額を事項に分けて列挙している**（少なくとも確認した2例では）。事項ノードの合計＝目になるので、「その他」で差額を埋める必要はない見込み。検算の式も立てられる。

**注意点**

- 説明欄には課（担当部署）が書かれていない。課は E・G から補う（2.3）。
- 「職員費 293人」のように人件費が事項として入る。事業費と人件費を分けて見せるかは設計で決める。
- 1つの目が複数ページにまたがる（節の列が長い）。ページをまたいだ結合が必要。
- 年度で画像の品質が違う: **R8 は 150dpi カラー（JPEG2000）、R7（`259281.pdf`）は 300dpi 白黒（CCITT）**。R7 のほうが OCR しやすい可能性がある。
- 歳入も同じ様式（款・項・目・節。説明欄はほぼ空）。歳入→会計のサンキーも作れる。
- 特別会計は一般会計と同じ様式（国民健康保険特別会計 印字492で確認）。公営企業会計は様式が違う（収益的収支・資本的収支）。

### 2.3 編成概要の施策別資料（E）の構造

テキストで取れる。1行の単位は次のとおり（柱1 の8ページ目で確認）。

```
区分（取組事項） / 課名 / 科目（款 項 目 の番号） / 事項名 / 予算額（括弧内は前年度額） / 説明（○内訳 金額、[新] の印）
例: 国際政策課 / 2 2 5 / 海外福岡県人会と連携したグローバル人材育成費 / 2,485（3,456） / ○海外県人会と連携した派遣事業の合同報告会…
```

- 粗い集計で**約650行・約1,700億円**（一般会計 2兆3,000億円の1割弱）。**主要事業だけ**なので骨組みには使えない。
- 「科目（款・項・目の番号）＋事項名」で、説明書の説明欄の事項と結び付けられる見込み。結び付けば、その事項に**課名・施策の柱・取組事項・説明文・新規の印**が付く。
- G（見直し一覧）も「部名・課名・事項名」を持つ。

**照合の見込み（試算）**

- 評価266事業の名前が E（施策別資料）の本文に出てくるのは **57件**（完全一致6・語尾「事業」「費」を除くと51）。名前だけの照合では足りない。
- 評価書には **R8 当初の事業費（合計 約262億円）** があるので、**説明欄の事項の金額と一致するか**で照合するのが有望（説明書の OCR 後に検証する）。
- 評価の事業は「○○事業（△△事業）」のように、予算の事項の一部や複数事項の組み合わせのことがある。1対多・多対1を許す対応表にする。

### 2.5 契約情報（I・J）— 支出先の層の候補

当初の想定（支出先データはない）から変わった点。

- **建設工事の入札結果（I）は Excel で、契約者名と契約金額が取れる**（予定価格400万円以上、部局別・四半期）。
- **特命随意契約（J）は所属課・相手方・金額・理由が取れる**（テキスト PDF、部局別・四半期）。
- ただしどちらも**予算の事項（款・項・目）とは直接結び付かない**。結び付けられるのは部局・課・事務所の単位まで。
- 委託・物品の一般競争入札の結果は案件ごとの HTML ページにばらばらに載っている。補助金の交付先の一覧は見つかっていない。

→ 国版の「事業 → 支出先」のようにサンキー図の最後の列にはせず、**部局・課の単位の「契約先」ビュー（国版の `/vendors` 相当）として別にする**のが妥当。MVP の範囲外。

## 3. 可視化の設計方針

### 3.1 サンキー図の列（案）

```
歳入（款: 県税・地方交付税・国庫支出金・県債 …）
  → 会計（一般会計 / 特別会計 / 公営企業会計）
    → 款（14款）
      → 項
        → 目
          → 事項（説明欄の ○事項名）
```

- MVP は**一般会計の歳出（款 → 項 → 目 → 事項）**。左端に歳入の款（または財源内訳: 国庫支出金・地方債・その他特定財源・一般財源）を付ける。
- 事項の補足情報（詳細パネル）: 節（性質）の内訳、財源内訳、前年度比較、課名・施策の柱（E から）、見直し（G から）、成果指標（H から）。
- 色分けの候補: 款ごと、または性質（人件費・扶助費・普通建設事業費 … は節から推計）。

### 3.2 国版との違い（全体計画3章に追加）

- 国版の「所管（府省庁）」に当たる担当部署が、県の予算書の骨組みには**ない**（款は目的別の分類で、部局とは一致しない）。部局で絞り込むには、事項に課名を付ける（E・G・H との照合）必要がある。照合できない事項は「部局不明」とする。
- 国版の支出先の列はなくなる（2.5）。

### 3.3 対象年度

- MVP は R8 当初予算（最新。H の「R8当初」の事業費と突き合わせられる）。
- 前年比較は説明書の「前年度」列で目の単位までできる。事項単位の前年比較は R7 の説明書も取り込む必要がある（R7 は 300dpi で OCR しやすい可能性）。

## 4. データパイプライン（案）

`scripts/local-gov/fukuoka-pref/` 配下。

1. **取得**: 公式ファイルをダウンロード（リポジトリにはコミットしない。URL と SHA256 を記録）
2. **基準値の抽出**（D・テキスト）→ 会計別・款別の総額
3. **説明書の OCR → 表の復元**（A・B。方式は検証してから決める。候補: 罫線でセルを切り分けて OCR／画像を読める LLM）
   - 検算（すべて通るまで直す）: 説明欄の合計＝目／節の合計＝目／財源内訳の合計＝目／目の合計＝項（「計」行）／項の合計＝款／款の合計＝D の基準値
4. **施策別資料の抽出**（E・テキスト）→ 課名・科目・事項名・施策分類
5. **照合**: 説明書の事項 × E・G（科目＋事項名）× H（金額＋名前）。対応表と照合率を出す
6. **JSON 生成** → `.gz` で Git 管理
