## 2. 三基金の推移と見込み

### 2.1 何を描くか

県が財政改革プランで目標を置いている「**財政調整基金等三基金（財源調整分）**」＝
財政調整基金（通常分）＋減債基金（通常分）＋公共施設整備基金。

- 交付税精算分等（普通交付税から後で減らされる分を積んだもの）と、減債基金の公債管理特別会計分（満期一括償還の備え）は**含まない**。
  今の推移のグラフ（調書の全額）とは額が大きく違うので、見出しと説明でそう書く
- 実績: 各年度の「基金積立状況」（県の基金の公表のページ、H29〜R7 の9年分）の年度末残高
- 見込み: 「令和8年度当初予算・令和7年度2月補正予算の概要」p.1 の「8年度末見込 714億円」（財政改革プランの目標達成状況）
- 目標: 同じ表の「令和8年度末の三基金残高を 400億円〜500億円確保」

確かめた値（千円。R7 は令和7年度基金積立状況）:

| 年度末 | 財政調整基金（通常分） | 減債基金（通常分） | 公共施設整備基金 | 計 |
|---|---|---|---|---|
| R6 | 38,722,356 | 21,357,444 | 13,121,376 | 73,201,176 |
| R7 | 40,492,626 | 21,641,501 | 13,217,835 | 75,351,962 |

- H29〜R2 の資料には「通常分」の行がない。減債基金の通常分 = 減債基金 − 公債管理特別会計分（交付税精算分は R3 から）、
  財政調整基金は全額が通常分（交付税精算分等は R4 から）として求める。書き出しで内訳の足し上げを確かめる（3.2）
- 基準: 基金積立状況の年度末残高は、出納整理期間の分を含む（財政調整基金は現金だけ。調査メモ 1章）。
  今の推移のグラフ（調書の3月31日現在高）と基準が違うので、**同じグラフに重ねない**（別のグラフにする）

### 2.2 グラフ

- 線グラフ1本（縦軸は億円の1本だけ）。実績は実線＋点、R7 末 → R8 末見込みは**点線**＋白抜きの点。
  見込みの点に「8年度末見込み 714億円（当初予算の時点）」と直接ラベル
- 目標の帯: 400〜500億円を薄いラベンダーの帯で横に引き、帯の端に「財政改革プランの目標（8年度末）」とラベル
- 色: 線はラベンダー（`#7a6cc0`、地方版の主色）。系列が1本なので凡例の箱は出さず、見出しで名前を言う
- ホバー（タッチは押す）で年度・額・（実績なら）3つの内訳、（見込みなら）出典と「補正で変わる」をツールチップに出す
- グラフの下に同じ値の表を `<details>` で折りたたんで置く（色に頼らず読めるように）
- スマートフォン: 幅に合わせて縮める。年度のラベルは1つおき（H29・R1・R3・R5・R7・R8見込み）

### 2.3 断り書き（グラフの下）

- 見込みは県が当初予算を組んだ時点（2026年2月）のもの。補正予算と決算で変わる。このサイトでは推計していない
- R8 末の実績は、令和8年度基金積立状況（例年、翌年度の秋ごろ）が出たら差し替える

## 3. データ

### 3.1 ファイル

新しいファイル `public/data/local-gov/fukuoka-pref/fiscal-indicators.json`（基金の見込みと指標をまとめる。決算や予算のファイルとは時点が違うので分ける）。
`index.json` の `datasets` に `kind: 'fiscal'` として載せる。

```ts
interface LocalFiscalFile {
  schema_version: 1;
  gov_id: string;
  /** 財源調整用の基金（県が目標を置いている合計） */
  reserve: {
    label: string;            // 「財政調整基金等三基金（財源調整分）」
    parts: string[];          // ['財政調整基金（通常分）', '減債基金（通常分）', '公共施設整備基金']
    history: { year: number; total: Yen; parts: Yen[]; source: string; page: number }[];
    outlook: { year: number; total: Yen; as_of: string; source: string; page: number } | null;
    target: { year: number; min: Yen; max: Yen; plan: string; source: string; page: number } | null;
  };
  indicators: {
    key: 'fiscal_capacity' | 'current_balance' | 'debt_service' | 'future_burden';
    label: string;            // 財政力指数・経常収支比率・実質公債費比率・将来負担比率
    unit: '' | '%';
    /** 早期健全化基準（実質公債費比率 25%・将来負担比率 400%。ほかは null） */
    threshold: number | null;
    values: { year: number; value: number; group_avg: number | null; source: string }[];
  }[];
}
```

- 金額は1円単位（資料の千円を円に直す）
- `source` は `sources.json` の id（基金積立状況の各年度・当初予算の概要・財政状況資料集の各年度を足す）

### 3.2 作り方（`scripts/local-gov/fukuoka-pref/extract_fiscal.py`）

- 基金積立状況（文字の PDF）: `pdftotext -layout` で、財政調整基金・減債基金・公共施設整備基金の行と、通常分・交付税精算分等・公債管理特別会計分の行を読む
  - 確かめること（合わなければ止まる）: 内訳の計 = 親の行（年度末残高）／前年度の年度末 = 次の年度の前年度末残高（H29〜R7 でつながる）
- 当初予算の概要 p.1: 「８年度末見込」「400億円～500億円」の行を読む（読めなければ止まる。数字は手で写さない）
- 財政状況資料集（総務省、都道府県別の xlsx）: R6 版（R2〜R6。確かめ済み）と R1 版（H27〜R1 の見込み。実装のときに確かめ、無ければ取れる年度だけにする）の「財政比較分析表」から4つの指標の値とグループ内平均を読む
  - 確かめること: 「総括表」の本年度・前年度の値が、財政比較分析表のその年度の値と一致
  - 財政力指数は3年平均（資料の値をそのまま。小数第2位まで出す）
- 出力の要約行を回帰テスト（`tests/regression.py`）の対象に足す（例: 「三基金 9 年分（H29〜R7）・見込み R8 714億円・指標 4 種 × 10 年」）
- 資料が公表されたら年度を足す: 基金積立状況（秋）・財政状況資料集（翌年の春ごろ）

### 3.3 画面側の確かめ（`app/lib/local-gov/validate.ts`）

- 三基金: 年度が連続し重複なし、parts の計 = total、見込みの年度 = 実績の最後の年度 + 1、目標の min ≤ max
- 指標: 4種がそろう、年度が重複なし、値が数、threshold は実質公債費比率・将来負担比率だけ

## 4. 財政の指標の区画

### 4.1 見せ方

4つの小さな線グラフを並べる（パソコン 2×2、スマートフォン 1列）。それぞれ縦軸は自分の単位の1本だけ（2つの量を1つのグラフに重ねない）。

| 指標 | 一言の説明（画面） | 良い向き |
|---|---|---|
| 財政力指数 | 標準的な行政に要るお金のうち、県の税などでまかなえる割合（3年平均）。1 に近いほど自前でまかなえる | 高いほど |
| 経常収支比率 | 毎年入るお金のうち、人件費・社会保障・借金の返済など毎年決まって出ていくお金に回る割合。高いほど自由に使える分が少ない | 低いほど |
| 実質公債費比率 | 収入に対する借金の返済の重さ（3年平均）。25% を超えると早期健全化の対象 | 低いほど |
| 将来負担比率 | 収入に対する、県債の残高など将来払う負担の重さ。400% を超えると早期健全化の対象 | 低いほど |

- 線: 福岡県 = ラベンダーの実線、グループ内平均 = 灰色の点線。凡例は区画の上に1つ（系列が2本）、最新の年度の値は線の端に直接ラベル
- 早期健全化基準は線にしない（400% を入れると縦軸が伸びて推移が読めない）。カードの見出しの横に「基準 400%」と文字で出す
- 「グループ内平均」は「財政力の近い都道府県の平均（総務省の分類）」と説明する
- ホバー・押すで年度・値・グループ内平均のツールチップ。下に値の表（`<details>`）
- 県ごとの順位（47都道府県の中の位置）は今回は出さない（47ファイルの取り込みが要る。後で足せる形にしておく）

### 4.2 断り書き

- 決算の数字。R7 決算の値は、総務省の財政状況資料集の R7 版が出たら足す
- 経常収支比率は、減収補塡債（特例分）・臨時財政対策債を歳入に含めた値（資料の主の値）

## 6. 確かめ方

- Python の単体テスト: 通常分のない年度の求め方、内訳の計が合わない・年度がつながらないと止まること、xlsx の総括表との突き合わせ
- `npm test`: validate の各条件の否定、fiscal.ts の点（見込みが最後の実績の次の年度・点線の区間）
- 回帰テスト: 全ステップで差分 0（足した要約行だけ増える）
- 画面: パソコン・スマートフォンの縦・横で撮る（横スクロールなし・ラベルの重なりなし・コンソールのエラー 0）。色は dataviz の検査を通す（ラベンダーと灰の2色）
- typecheck・lint
