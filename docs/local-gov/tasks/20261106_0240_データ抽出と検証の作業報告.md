## 3. 説明書（スキャン画像）の OCR 検証

対象: R8 当初予算に関する説明書（一般会計、`281298.pdf`、PDF 9〜420ページ）。300dpi・RapidOCR・列ごとの切り出し（方式はノウハウ 6章）。
所要時間: 3並列で約 40 分（412ページ）。

### 3.1 結果（検算の合否。単位は千円）

|---|---|---|---|---|---|---|
| 歳出 | 232 | 197（うち説明欄が空で対象外 9、入れ子の内訳を除いて一致 10） | 228 | 227 | 226 | **188（81.0%）** |
| 歳入 | 151 | — | — | 142 | 146 | **140（92.7%）** |

**款の合計: 歳出 14款・歳入 15款のすべてで、目の本年度の合計が計上額調（テキスト PDF）と千円単位まで完全一致**
（一般会計の総額 2,300,027,028 千円をスキャン画像から再現）。途中経過は 23款 → 26款 → 29款（以下の対策による）。

- 全部一致した歳出の目の本年度の合計は 1兆1,252億円（歳出 2兆3,000億円の約 49%）。教職員費など大きな目に未一致が残る
- 項の「計」の行との一致: 74件中 65件

### 3.2 失敗の原因と、直したもの

| 原因 | 影響 | 対応 |
|---|---|---|
| 罫線の取り違え（列見出し内の短い線） | 右寄せの数字の末尾が欠ける | 表の高さの半分以上の縦線だけを罫線に（直した） |
| 列見出しのない続きのページ | ページ上部（前の目の続き）を見出しとして捨てる。節の合計が合わない | 見出し語の有無で判定（直した） |
| 1ページに複数の表 | 途中の項の見出しを列の中身として読む | 縦線が途切れる高さで表を分ける（直した） |
| 節と細節の区別 | 名前が2行の節の番号が別の文字になり、細節と誤認 | 字下げの位置で区別。歳入はすべて節（直した） |
| 縦線の検出漏れ（p238） | 10列の表として読み飛ばし、5款が 3,100 万円ずれる | 節の列をいつもの位置で分ける（直した） |
| 「1」が l・I と読まれる | 款の合計が 1 ずれる | 数字の文脈に限り置換（直した） |
| 本年度「1」の取りこぼし | 款の合計が 1 ずれる（5款） | セルを拡大して再 OCR（`ocr/refill_missing.py`）で 3款を解消。2款は未解決 |
| 説明欄の入れ子 | 親の事項（「中小企業振興資金融資費 214,794,000」）の下に字下げした内訳が並び、全部足すと合計が親の分だけ大きくなる | 書き出し位置で親子を分け、親だけで照合（10目を解消）。内訳は `内訳: true` で保持 |
| 説明欄の金額が名前とつながる・読めない | 説明欄の合計が本年度より小さい | **未対応** |

### 3.3 名称の精度

名称（目名・事項名）は中国語モデルのため簡体字・誤字が混じる（例「維持修善費」← 維持修繕費、「電子果庁」← 電子県庁）。
**金額は検算で正しさを担保できるが、名称はできない**。名称は次の方法で正す必要がある:
- 目名: R6 決算の款項目別明細表（テキスト）の目名と、款・項・目の番号で突き合わせる（目の構成は年度でほぼ同じ）
- 事項名: 施策別資料（テキスト、1,083事項）の事項名と、科目＋金額で突き合わせる。残りは目視確認
