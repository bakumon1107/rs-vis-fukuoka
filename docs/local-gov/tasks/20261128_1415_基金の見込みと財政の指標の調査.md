## 1. 基金を令和8年度予算からの見込みとして点線で出せるか

### 使える資料

| 資料 | 中身 | 基準 |
|---|---|---|
| 令和8年度当初予算・令和7年度2月補正予算の概要（`277131.pdf` p.1） | **財政調整基金等三基金残高（財源調整分）の令和8年度末見込 714億円**（財政改革プランの目標 400〜500億円） | 県の公式の見込み（2月時点） |
| 令和7年度基金積立状況（基金の積立状況の公表のページ） | 34基金の令和6年度末残高・令和7年度の積立額（財源別）・取崩額・**令和7年度末残高**。H29〜R7 の各年度版がある | 下を参照 |
| 実質収支・財産に関する調書（決算のページ） | 今の基金の推移の出典（年度末 3月31日・出納閉鎖日 5月31日の現在高） | **R7 版はまだ載っていない**（最新は R6） |

- 基金積立状況の「令和6年度末残高」は、ほとんどの基金で調書の**出納閉鎖日（5月31日）現在高**と一致する
  （減債基金 777,468,806千円・地域づくり基金・環境保全基金・出産・子育て安心基金で確かめた）。
  ただし財政調整基金だけは 67,473,636千円で、調書の出納閉鎖日の**現金だけ**（一般会計貸付金 23,253,808千円を含まない）
- 今の基金の推移のグラフは調書の**年度末（3月31日）現在高**で描いている。積立状況の R7 末の値をそのままつなぐと基準が混ざる

### やり方の案

- **案A（推奨）: 三基金（財源調整分）の推移を別のグラフにし、県の公式の見込みを点線で足す**
  - 実績: 各年度の基金積立状況から「財政調整基金（通常分）＋減債基金（通常分）＋公共施設整備基金」（H29〜R7）
  - 見込み: 当初予算の概要の「8年度末見込 714億円」を R7 末から点線でつなぐ。目標の帯（400〜500億円）も薄く出す
  - 県が自分で出した見込みなので、こちらで推計しない。断り書き: 当初予算の時点の見込み（補正で変わる）
- 案B: 基金ごとに「R7 末 + R8 予算の積立 − 取崩」の点線。R7 の調書（3月31日）が載るまで起点が基準に合わない。
  また予算の取崩しは決算では実行しないことが多く（財政調整基金）、一般会計との出入りしか数えていないので、見込みは低めに出る
- R7 の調書が載ったら、今の推移のグラフに R7 末を足す（「R7 決算の基金」の作業。これは案A と別に進められる）

## 2. 財政の指標（財政力指数・経常収支比率など）を入れられるか

入れられる。毎年度、決算の数字として公表されている。

| 指標 | 意味（画面の説明の下書き） | 出典の候補 |
|---|---|---|
| 財政力指数 | 標準的な行政に要る額のうち、自前の収入でまかなえる割合（3年平均。1 に近いほど余裕） | 県の普通会計決算の概要・総務省の財政状況資料集 |
| 経常収支比率 | 毎年決まって入るお金のうち、毎年決まって出ていくお金（人件費・社会保障・借金返済）に使う割合（高いほど自由に使える分が少ない） | 同上（R6 95.6%・R5 97.3%） |
| 実質公債費比率 | 収入に対する借金返済の重さ（3年平均。早期健全化基準 25%） | 健全化判断比率の公表 |
| 将来負担比率 | 収入に対する将来払う負担（県債残高など）の重さ（早期健全化基準 400%） | 同上 |

- 年度ごとの推移（10年程度）と、全国の都道府県の中での位置（総務省の資料なら全団体の値がそろう）を出せる
- 置き場所の案:
  1. **トップの下に「財政の健康診断」のカード**（4つの指標の最新値と推移の小さな線。押すと詳しい説明）
  2. **基金のタブを「基金と財政の指標」にする**（三基金の見込みとあわせて「お財布の余裕」を1か所で見る）
  3. 「データについて」の下に参考として置く（目立たない）
- 置き場所を決めてから、出典（県の公表資料か総務省の資料集か）を確かめて設計書を書く
