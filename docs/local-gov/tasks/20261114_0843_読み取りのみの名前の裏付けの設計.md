# 読み取りのみの名前の裏付けの設計（福岡県 R8 当初予算）

状態: **ユーザー了承済み（2026-11-14。進め方の大枠）**。細部はこの設計書のとおり進め、結果を報告する。

関連: [名前の補正の設計](20261106_1241_名前の補正の設計.md)（裏付けの付け方・名前の修正表）、
`scripts/local-gov/fukuoka-pref/name_evidence.py`（読み取り・資料の全文検索での裏付け）、
`scripts/local-gov/fukuoka-pref/ocr/corrections/r8-names.json`（画像で確かめた名前の修正表）

## 1. 目的

R8 当初予算の公開データで、名前の出典が「読み取りのみ（ocr）」の名前に裏付けを付ける。読み違いは直す。
画面ではこの名前に「※名前は読み取り」の印が付いている（詳細パネル）。

対象（2026-11-14、PR #5 の後の公開データ）: **説明欄の事項 128件・細節 64件**（款・項・目・節は 0件）。

## 2. 方針

ユーザーの考え: 福岡県のホームページの資料で見つかるのが一番。国（総務省など）の資料と一致すれば確か。
ネット検索を3件試した結果（「九州各県等宣伝事業参加費」「海外移住振興費」「指導職員設置事務費」）はどれも見つからなかった
（検索エンジンが予算の PDF の中の細かい事項名まで拾わない）。そこで、**県のサイトの資料を手元に集めて全文検索の資料（corpus）に足す**のを主にし、
ネット検索は残りに使う。

裏付けの強さ（名前の出典）は今の決まりのまま:
- 手元の資料の全文に同じ名前がある → `search`（`name_evidence` に資料の id）
- 画像で確かめて修正表に記録 → `correction`
- 機械的な「近い名前への置き換え」はしない（2章の実例）。近い名前は候補として画像で確かめ、修正表に入れる

## 3. 細節（64件）

細節の名前は県の中でほぼ決まった言い方（「食糧費」「光熱水費」「普通旅費」）なので、辞書と突き合わせる。

- 辞書: R6 決算事項別明細書（テキスト PDF。`extract_kessan_setsu.py` の細節の名前で、文字コードのあるもの）と、
  R8 の公開データで裏付けのある細節の名前（40種類）
- 試した結果（2026-11-14）: **完全一致 42件・近い名前のあるもの 22件・見当なし 0件**
  - 完全一致は、決算事項別明細書（テキスト）に同じ名前がある → `search`（資料 `r6-kessan-jikou`）。全文検索の資料にはすでに入っているので、
    検索で見つからなかった理由（細節の名前は表の中で字間が空いている・1字ずつの層がある）を調べ、全文検索で見つかるようにするか、
    細節の辞書の突き合わせを裏付けの方法に足す（`reference` と同じ扱い。辞書の出典を記録）
  - 近い名前の 22件は読み違い（字の抜け「の他需用費」・簡体字「光热水費」「贿材料費」・取り違え「肇耕翻訳料」）。
    **機械的には置き換えない**: 「き地手当」の一番近い辞書の名前は「地域手当」だが、正しくは「へき地手当」（辞書になかった）。
    ページ画像の切り抜きで確かめ、名前の修正表（`level: sub`。目の id・節の番号・細節の金額で特定。修正表に sub の level を足す）に記録する

**結果（2026-11-14）**: 64件すべてをページ画像（300dpi の切り抜き）で確かめ、名前の修正表に `level: sub` で記録した（出典は correction）。
辞書の突き合わせは候補を出すのに使っただけで、裏付けの方法には足さない（全件を画像で確かめられたので、`reference` の扱いを決める必要がなくなった）。
- 読み違いだった 22件: 「肇耕翻訳料」「耕翻訳料」「筆翻訳料」→ 筆耕翻訳料（5件）、「の他需用費」「その他需用月費」→ その他需用費、
  「の他役務費」→ その他役務費、「休勤務手当」→ 休日勤務手当（2件）、「光热水費」→ 光熱水費（2件）、「き地手当」→ へき地手当（2件）、
  「贿材料費」→ 賄材料費（2件）、「普通通旅費」「通旅」→ 普通旅費、「勤手当」→ 勤勉手当、「児童当」→ 児童手当、「社会保料」→ 社会保険料、
  「費用弁」→ 費用弁償
- 残りの 42件は読み取りのとおりだった（出典だけ ocr → correction）
- 8款2項5目の 30千円は、同じ目に「その他役務費 30」もある。節の番号（10 需用費）で「光熱水費」に絞れることを画像で確かめた
- 公開データの差は細節の名前・名前の出典だけ（金額・一致数は変わらない。PR #5 の公開データと比べて確認）

## 4. 説明欄の事項（128件）

1. **集める資料の候補**（福岡県のサイト。文字の入った PDF だけ。スキャン画像は全文検索に使えない）:
   - 過去の年度の「予算に関する説明書」（R7 はスキャン画像だった。R6・R5 など、文字入りの年度があるか調べる）
   - 過去の年度・今年度の「施策別資料」「主要施策の成果」（一部は corpus に入っている）
   - 各課の事業の資料（補助金の交付要綱など。事項名が事業名と同じことがある）
   集めた資料は sources.json に `corpus: true` で足し、URL・SHA256・取得日を記録する（原本はコミットしない）
2. **一般的な名前**（「職員費」「事務費」「運営費」など）: どの資料にも出るので、全文検索で見つかっても裏付けとしては弱い。
   今の全文検索は語の切れ目を見て「長い語の一部」を除いているが、一般的な名前はそもそも正しい。
   **一般的な名前の一覧**（R8 の裏付けのある事項名で 10回以上出る名前など）に入る名前は、別の出典（`generic`）を足さずに `search` でよいか決める（5章）
3. 残り: ネット検索（`site:pref.fukuoka.lg.jp "<事項名>"`。国の制度の名前（交付金・補助金）なら国の資料も）。見つかった資料は 1. と同じく corpus に足す
4. それでも残るもの: ページ画像の切り抜きで確かめ、名前の修正表に記録する
