## 2. 福岡県予算ビューとの比較

| 観点 | 事例 | 福岡県の現状・計画 | 判断 |
|---|---|---|---|
| 財源で始まる流れ図 | 両方とも「一般財源／特定財源」を左に置く | 計画は「歳入の款 → 会計 → 款 → 項 → 目 → 事項」。財源内訳は目ごとに抽出済み（国庫支出金・地方債・その他・一般財源） | **取り込む**。目ごとの財源内訳があるので、推計なしで「財源 → 款」が描ける（佐久市のような逆算は不要） |
| 粒度 | 款・項まで | 目・説明欄の事項まで（一般会計 383目、全検算一致） | 福岡県はより細かい。事項まで見せられるのが強み |
| 補正後の切り替え | 佐久市はあり | 設計書あり（確認待ち） | 補正の設計書の MVP 案（当初と最新の補正後の切り替え）と同じ考え方。妥当性の裏付けになる |
| 1人あたり | 佐久市はあり | 計画になし | **取り込む候補**。人口（住民基本台帳の時点）を出典つきで持つ |
| 主要事業の並べ替え | 金額・増減・議会での言及 | 施策別資料（1,083事項・前年度額あり）・行政評価（266事業）を抽出済み | **取り込む候補**。増えた額・減った額は前年度額で出せる。議会での言及は `mirai-gikai-fukuoka-pref`（県議会の会議録を扱う）と連携できる可能性 |
| 説明と出典・検算の明記 | 文京区は「款・項の合計が資料の合計と一致」と明記 | 検算はもっと細かい（目・項・款・予算書・文字層の突き合わせ） | **取り込む**。画面に「どう確かめたか」を載せる（信頼の根拠になる） |
| 誤りの報告 | フォームへのリンク | なし | 取り込む候補（国版の意見機能との関係は別途） |
| 推計の扱い | 佐久市は推計を明記 | 方針として値ごとに出典（OCR・文字層・修正表・推定）を持つ | 方針は同じ。画面でも推計・修正の印を出す |

## 3. 設計に反映する点（提案。各設計書で扱う）

1. **流れ図の左端を「財源」にする選択肢**を画面の設計に入れる（歳入の款 ↔ 一般財源／特定財源 の切り替え）
2. **1人あたり換算**を共通 JSON 形式の設計に入れる（人口・時点・出典）
3. **主要事業の一覧**（金額・増減・新規の並べ替え）を MVP の候補に入れる。議会での言及は MVP の後
4. **「説明と出典」ページ**に、検算の方法と結果、推計・修正した値の一覧を載せる
5. 地方版は他にも作られている。汎用化（どこでも用）のときは、こうした事例の自治体（文京区・佐久市）も読み込めるかを試金石にできる
