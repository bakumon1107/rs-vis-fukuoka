# 一般財源の中身の設計（一般会計の見方で「一般財源」の箱を押したとき）

関連: [画面とグラフの設計](20261106_1327_地方版サンキー図の画面とグラフの設計.md) 4章の末尾（未実装の MVP の残り。
「根拠の資料を確かめてから作る。按分の推計はしない」）、[財源内訳と歳入の款の差の調査](../fukuoka/20261114_0005_財源内訳と歳入の款の差の調査.md)

## 1. 目的

一般会計の見方の左端「一般財源」（R8 当初 1兆6,586億円）を押したときに、その中身（県税・地方交付税など）を見せる。
前の設計では「一般財源に数える歳入の範囲が分からない（調整債・臨時交付金がどこに入るか未確認）」ため保留していたが、
財源内訳の調査（2026-11-14）で、説明書から**千円の位まで中身を説明できる**ことが分かった。

## 2. 中身（R8 当初・一般会計。千円）

| 中身 | 額 | 根拠の強さ |
|---|---|---|
| 県税 | 830,805,619 | 歳入の款そのもの（使い道の決まっていない収入） |
| 地方消費税清算金 | 298,598,935 | 同上 |
| 地方譲与税 | 126,605,150 | 同上 |
| 地方特例交付金 | 18,194,489 | 同上 |
| 地方交付税 | 314,283,866 | 同上 |
| 交通安全対策特別交付金 | 870,606 | 同上 |
| 国庫支出金のうち 物価高騰対応重点支援地方創生臨時交付金 | 6,660,172 | 財源内訳の合計どうしの差と歳入の節が千円の位まで一致 |
| 県債のうち 調整債 | 13,335,700 | 同上（歳入の目） |
| 繰入金のうち 財政調整基金・減債基金・特別会計繰入金 | 32,461,202 | 財源の名前ごとの足し上げの差が、歳入の目の合計と千円の位まで一致 |
| 寄附金のうち（一般寄附金） | 1,059,000 | 同じ足し上げから求めた額（使い道の決まった 603,764 を除いた残り） |
| 繰越金 | 1 | 歳入の款そのもの |
| 諸収入・財産収入・使用料及び手数料のうち | 15,724,888 | **差し引き**（一般財源の合計 − 上の計）。足し上げの概算 15,725,746 と 858 違う（足し上げの総計と財源内訳の合計の差と同じ額。寄附金と3つの収入の間の振り分けの誤差は確かめていない） |
| **計** | **1,658,599,628** | 財源内訳の一般財源の合計と一致 |

- 歳入の款そのものの6つ（計 1,589,358,665）は、公開データの歳入の目から足すので、データが変われば自動で追う
- 組み替えの5つ（臨時交付金・調整債・繰入金・寄附金・諸収入など）は説明書を読んで確かめた額なので、**資料と根拠つきの表**で持つ（次章）
- 最後の行は差し引きなので、合計は必ず一致する。差し引きの額と足し上げの概算が大きく違ったら（1億円以上など）書き出しで止める

## 3. データの持ち方

今は組み替えの説明文を画面のコード（`client/lib/local-gov-labels.ts` の `FUNDING_RECLASS_NOTES`）に書いている（/code-review で「データと結び付いていない」と指摘あり）。これを改める:

- `scripts/local-gov/fukuoka-pref/funding/r8-initial.json`（新規）: 組み替えの額・歳入の目の id・根拠の強さ・説明文・調べた日
- 書き出し（`export_fukuoka_pref.py`）が、歳入の目の合計と組み替えの表から `general_fund`（中身の行の配列。各行に額・出典・根拠の強さ）を作り、
  予算のファイルに入れる。**合計 = 財源内訳の一般財源の合計** を書き出しで確かめ、合わなければ止める（`validate.ts` でも確かめる）
- 画面の「データについて」の説明（`#funding`）もこのデータから作る（`FUNDING_RECLASS_NOTES` をやめる）

## 4. 画面

- 一般会計の見方で「一般財源」の箱を押すと、図の下（広い画面）・下からのシート（スマートフォン）に「一般財源の中身」の表を出す（目を押したときの詳細と同じ場所）
- 図は変えない（一般財源の帯を中身で分けて描くと、按分の推計が要る。按分の推計はしない、の決定のまま）
- 表の各行に根拠の強さを小さく添える（「説明書で確かめた」「足し上げから求めた額」「差し引き」）。「データについて」の #funding へのリンクを付ける
- 決算（R6）の見方: 決算は歳出の財源内訳がないので、この表は出さない（予算だけ）

## 5. テスト

- 書き出し: 中身の合計 = 財源内訳の一般財源（R8 当初で 1,658,599,628）。組み替えの表の歳入の目の id が実在すること
- `validate.ts`: `general_fund` の合計の一致
- 画面: 一般財源の箱を押したときだけ表が出る（ほかの財源の箱・款では出ない）

## 6. 決めること（確認待ち）

1. この中身の出し方（表で見せ、図の帯は分けない）でよいか
2. 差し引きの行（約157億）の見せ方: 「諸収入・財産収入・使用料及び手数料のうち（差し引き）」でよいか。財産収入の約26億は中身まで分かっている（調査 3.4）ので、内訳の注に書く
3. 組み替えの説明文の置き場所をデータ側に移す（3章）のを、この作業でまとめて行うか
