# かんたんの図に歳入から財源への振り分けを足す設計（財源の色分けを含む）

## 1. 何をするか

かんたんの図（一般会計・当初予算）を、今の「財源 → 歳出の款」の2列から、
**「歳入の款 → 財源 → 歳出の款」の3列**にする。歳入のどのお金が、使い道の自由な一般財源になり、どの分野へ流れるかを1枚で見せる。
あわせて、この図の帯を**財源の4区分の色**で塗る（くわしくの図は今の列ごとの色のまま）。

- 小諸市の予算ビューの見せ方（歳入 → 財源区分 → 款、財源区分の色分け、推計の帯の点線）を参考にするが、コードは持ってこない（考え方だけ。こちらで書く）
- 対象: 一般会計の見方・当初予算（一般財源の中身 `general_fund` があるファイル）だけ。補正後・決算・全会計・公営企業会計の見方は今の2列のまま

## 2. 振り分けの決め方（データの額で決まる。推計は1か所だけ）

歳入の款 K から財源 F への額を、次の順に決める（R8 当初の額で確かめた。単位は億円）。

| 財源 | 決め方 | R8 |
|---|---|---|
| 一般財源 | `general_fund` の行を、その行の歳入の款へ戻す。款そのもの（県税・交付税など）は款の全額、組み替え（臨時交付金・調整債・基金繰入金・一般寄附金）は refs の目の款へ、差し引きは下の「概算の振り分け」で3つの款へ | 16,586.00 |
| 国庫支出金 | 款「国庫支出金」 − そのうち一般財源へ行く分（臨時交付金） | 2,171.66 − 66.60 = 2,105.06（財源内訳の合計と千円まで一致） |
| 地方債 | 款「県債」 − そのうち一般財源へ行く分（調整債） | 1,687.24 − 133.36 = 1,553.89（一致） |
| その他 | 残りの款（諸収入・繰入金・使用料及び手数料・分担金及び負担金・財産収入・寄附金）の、一般財源へ行かない残り | 2,755.33（一致） |

- 「国庫支出金の款 → 国庫支出金」「県債 → 地方債」「ほか → その他」の対応は、**自治体ごとの定義ファイル**に書く
  （`scripts/local-gov/fukuoka-pref/funding/r8-initial.json` に `"歳入の款と財源"` を足す。市町村なら「県支出金 → 国県支出金」などを書ける）
- 書き出しで、財源ごとの合計が歳出の財源内訳の合計と一致すること・どの帯も負にならないことを確かめ、合わなければ止める（数字がずれたら3列を出さない）

### 概算の振り分け（差し引き 約157億円）

一般財源の「諸収入・財産収入・使用料及び手数料のうち（差し引き）」は、3つの款への分け方が説明書にない。
2026-11-14 の調査（`docs/local-gov/fukuoka/20261114_0005_財源内訳と歳入の款の差の調査.md` 3.3）で、
歳出の財源内訳の欄を財源の名前ごとに足し上げた款ごとの額がある:
諸収入 12,228,216千円・財産収入 2,635,509千円・使用料及び手数料 862,021千円（計 15,725,746千円 = 表の「概算」）。

- 差し引きの実額（15,724,888千円）との違い 858千円（読み取りの誤差）は、一番大きい諸収入で吸収する
- この3本の帯は**概算**として、縁を点線にし、帯の説明（ホバー・タップ）と凡例に「財源内訳の足し上げからの概算」と書く
- 定義ファイルに款ごとの概算を書き、書き出しが `general_fund` の差し引きの行に款ごとの内訳（`split`）として出す

## 3. 色分け

- 帯は**財源の色**で塗る（歳入の款 → 財源、財源 → 歳出の款の両方）。財源の箱もその色。歳入・歳出の款の箱は灰色
- 4色は、どれも「良い・悪い」を感じさせない色にする（地方債を赤にしない）。色の組は実装のときに dataviz の手順で、
  色覚の違いと明暗の両モードで見分けられることを確かめて決める（サイトのラベンダー基調に合わせる）
- 色だけに頼らない: 凡例に区分の名前、帯の説明に「歳入の款 → 財源 → 額」を出す
- くわしくの図は今の列ごとの色のまま（項・目の帯は財源が混ざるので、塗り分けるには帯を財源ごとに割る必要があり、図が込み入る）

## 4. 画面

- かんたんの図（一般会計・当初予算）を3列にする。下の一覧（歳出の款の金額の大きい順）はそのまま
- スマートフォンの幅（375px）で3列にすると、左の歳入の款（15）の名前が詰まる。小さい款（全体の 1% 未満など）を「その他の収入」にまとめ、
  名前の幅を確かめて決める（縦向き・横向きを撮って確かめる）
- 図の上に1行の説明「左が収入、まん中が使い道の自由度（一般財源は使い道が自由）、右が使い道（歳出の款）」
- 箱を押したときは今と同じく、くわしくの図でその箱を選ぶ（歳入の款の箱は、全会計の見方の歳入の款へ）

## 5. 作るもの

- `funding/r8-initial.json`: `"歳入の款と財源"`（款の名前 → national / bond / other）と `"差し引きの款ごとの概算"` を足す
- `general_fund.py`: 差し引きの行に `split`（款ごとの額。合計 = 差し引き）、各行に `kan`（refs の款）を付け、3列の帯の検算をする
- `types/local-gov.ts`: `GeneralFundRow` に `split?`。`app/lib/local-gov/` に3列のグラフを組み立てる純粋関数（`simpleFundingFlow`）
- `graph-view.ts` の `simpleDisplay`: 一般会計・当初で `general_fund` があれば3列、なければ今の2列
- `LocalSankeyChart.tsx`: 帯の色を「財源の色」で塗る指定（かんたんの3列だけ）・点線の縁・凡例
- テスト: 財源ごとの合計 = 財源内訳の合計、歳入の款ごとの合計 = 歳入の款の額、帯が負にならない、概算の帯の印

## 6. 作ったときに決めたこと（2026-11-28。ユーザーは推奨の案で了承）

- 差し引きは款ごとの概算で3本に分け、点線の縁にした
- 色（`LocalSankeyChart.tsx` の `FUNDING_COLORS`）: 一般財源 ラベンダー `#7a6cc0`・国庫支出金 アクア `#00b894`・地方債 黄土 `#d28e05`・
  その他 シエナ `#a0522d`。最初に考えた「青・灰」は、dataviz の `validate_palette.js` で青がラベンダーと見分けにくく（通常の見え方 ΔE 9.1・
  色覚の違い 1.5）、灰はその他を色として見分けにくい（彩度の下限）ので外した。ラベンダーを固定して3色の組を総当たりし、
  4色のどの組も通る（色覚の違い ΔE 13.1・通常 18.7、`--pairs all`）組を選んだ
- 歳入の款の並び: 一番多く流れる財源の順（財源の箱の並び）→ 額の大きい順（額の大きい順だけだと、国庫支出金・県債の帯が一般財源の帯と交差する）
- スマートフォンの幅（縦・横）では、歳入の合計の 1% 未満の款を「その他の収入」（選べない箱）にまとめる。まとめた帯に概算の分が入れば点線
- 歳入の款の箱を押すと、全会計の見方の歳入の款を開く（一般会計の見方に歳入の列がない）
- 帯にホバーの説明（「県税 → 一般財源（一般財源）額」、概算の帯はその旨）。凡例は図の下
