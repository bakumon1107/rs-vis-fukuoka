# 前年度にだけあった款をデータに足す設計

## 1. 何が足りないか

R8 当初予算の前年度比（PR #25）で、全会計の歳入の款「財産収入」の前年度が 2,530千円少ない。
県営埠頭施設整備運営事業特別会計の説明書 p.93（総括・歳入）にだけ、次の行がある。

| 款 | 本年度 | 前年度 | 比較 |
|---|---|---|---|
| 財産収入（番号なし） | 空欄 | 2,530 | △2,530 |

- 本年度が 0 なので、明細（項・目）のページがない。R8 の款の番号も付いていない（R8 は 1 使用料及び手数料、2 繰入金、3 県債…と付け直されている）
- 項・目の名前と番号は、R8 の資料のどこにもない（R7 の説明書を見れば分かるが、取り込んでいない）
- 前年度にだけあった**目**は、もう `previous_only`（目の番号は null、ID は `…-p<n>`）で行にしている。今回は**款**ごと前年度にだけある

## 2. 方針: 行にしないで、ファイルに「前年度にだけあった款」を持つ

行（目）にすると、項・目の名前と番号をこしらえることになる（「財産収入 / 財産収入 / 財産収入」のような名前、こしらえた番号）。
資料にないものは作らない決まりなので、行にはしない。代わりに、ファイルの直下に款の単位で持つ。

```ts
// types/local-gov.ts の LocalBudgetFile に足す（当初予算だけ。ないファイルは空とみなす）
/** 前年度にだけあった款（本年度は空欄で、明細のページも款の番号もない。総括表にだけ載る） */
previous_only_kan?: {
  account: string;          // 会計 ID
  side: Side;
  kan: { name: string };    // 番号は持たない（R8 の番号がない）
  previous: Value;          // 前年度（円）。src は ocr、agree は読み取りの一致数
  pages: PageRef[];         // 総括表のページ
}[];
```

- 図・行・合計（本年度）は何も変わらない（本年度は 0 で、帯も箱も出さない）
- `schema_version` は上げない（足すのは省略できる項目だけ。読む側は無ければ空とみなす）

## 3. 書き出し（export_fukuoka_pref.py）

- 値は、総括表の OCR を目で確かめて `scripts/local-gov/fukuoka-pref/ocr/corrections/r8-previous-only-kan.json` に書く
  （会計・歳入歳出・款の名前・前年度の千円・ページ・確かめた日）。総括表は表として読めていない（`tables` が空）ので、今は手で書く
- 書き出しで、**会計ごとに「歳入の前年度 + 前年度にだけあった款」= 歳出の前年度**を確かめ、合わなければ止まる
  （予算は歳入 = 歳出。合わなければ、前年度にだけあった款・目の取りこぼしか読み違い。テストで見つけた方法を書き出しの検査にする）。
  公営企業会計は除く（前年度の額を持たない）
- 回帰テストの期待値は、このファイルの増えた分だけ更新する

## 4. 画面（app/lib/local-gov/breakdown.ts ほか）

- `previousBoxValues`: 前年度にだけあった款を、歳入なら歳入の款の箱（`revenue:<款の名前>`）、歳出なら会計の箱の前年度に足す
  （番号がないので款の箱には入らない）。会計の箱は歳出で数えるので、歳入の款は会計の箱に入らない。
  本年度に同じ名前の箱がない款（どの会計にも本年度がない）は、箱がないので出さない（R8 の財産収入は一般会計に本年度があるので箱がある）。
  前年度が読めない（null）なら、その箱は前年度比を出さない（目と同じ）
- 内訳の表: 選んだ箱に前年度にだけあった款が入るとき（`previousOnlyKanIn`）、表の上に
  「前年度には、本年度はない県営埠頭施設整備運営事業特別会計の財産収入（253万円）を含みます。」と出す（行の前年度の合計と計の前年度が合わない理由）
- 補正後（`composeLatest`）では外す（前年度比を出さない。補正で同じ款が加わると食い違う）
- 検証（`validate.ts`）: 当初予算だけ・会計があること・前年度とページがあること・本年度の行に同じ款がないこと
- PR #25 で足した「総括表にだけ載る分は歳入の前年度に入っていません」の断り書きと `previousRevenueGap` は消す（データが揃うので）
- テスト: 会計ごとに歳入の前年度（+ 前年度にだけあった款）= 歳出の前年度、を例外なしで確かめる（PR #25 の既知の抜けの扱いを消す）

## 5. 確かめ方

- `npm test`・typecheck・lint、福岡県の回帰テスト（`scripts/local-gov/fukuoka-pref/tests`）
- 画面: 全会計の当初予算で「財産収入」を選び、前年度に 2,530千円が入ること・断り書きが出ること

## 6. やらないこと

- 総括表を表として読む仕組み（今は手で書いた値を書き出しで検査する）。他の年度・自治体に流用するときに考える
- R7 の説明書を取り込んで項・目まで埋めること
