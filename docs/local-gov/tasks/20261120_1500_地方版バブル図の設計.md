# 地方版バブル図の設計（福岡県 R8 当初・案 B）

- 状態: **確定（2026-11-20 ユーザー承認）**。決めたことは 7章
- 前提: [画面とグラフの設計](20261106_1327_地方版サンキー図の画面とグラフの設計.md) の「MVP の後に検討する」（2026-11-06 ユーザーと合意）。
  県の総合計画の分類（4つの柱 → 取組 → 事項）で事項のバブルを置き、大きさは予算額。款をまたぐ政策（ワンヘルスなど）の合計と広がりを見せる

## 1. 何が見えるようにするか

- サンキー図は款（目的別）の骨組みなので、**款をまたぐ政策の塊**が見えない。例: 取組「ワンヘルスの推進」の事項 13件は、
  衛生費（3款）・環境費（4款）・農林水産業費（6款）・教育費（10款）などに分かれる（施策別資料の科目で確かめた）
- バブル図では、柱 → 取組 → 事項 の入れ子の円で、**取組ごとの予算の合計と、その中の事項の広がり**を見せる。事項を押すと詳細（課名・科目・説明・前年度・新規）

## 2. 使う資料と今あるデータ

  抽出は `extract_shisaku.py` がすでにある（回帰テストのステップ「施策別資料」。出力 `shisaku.json`）
- 抽出済みの中身（2026-11-20 に数えた）: 事項 **1,083件**（新規 102件）。項目は 柱・区分（＝取組）・課名・科目（款 項 目）・事項名・予算額・前年度・説明

柱 2 の名前は抽出で行の途中まで（「…子どもを安心して産み育」）。続きは5章で直す。

## 3. 範囲（案）

- **一般会計の事項だけ**: 1,054件・約 7,775億円。除くもの:
  - 特別会計の事項 6件（国民健康保険保険給付費等交付金 3,551億円など）。一般会計のバブル図に混ぜると単位が揃わない
  - **債務負担行為** 23件（約 521億円）。予算額の欄にあるのは後年度にわたる限度額で、R8 の歳出ではない（事項名に「(債務負担行為)」）
- 一般会計の歳出は 2兆3,000億円なので、**図に載るのは約 1/3**。載らない約 1兆5,000億円は、中身ごとに**灰色の円に分けて**並べる
  （「施策別資料に載る事項の合計 7,775億円 / 一般会計の歳出 2兆3,000億円」も出す）。中身（説明書から数えた概数）:

  | 中身 | 額 | 数え方（説明書） |
  |---|---|---|
  | 地方消費税の清算金・市町村への税交付金 | 約 4,900億円 | 款「諸支出金」（清算金 2,931億・地方消費税交付金 1,555億など。通り抜ける税） |
  | 人件費 | 約 4,400億円 | 節 1〜4（報酬・給料・職員手当等・共済費）。教職員・警察官・職員の給与が大半 |
  | 公債費 | 約 2,600億円 | 款「公債費」 |
  | 中小企業の制度融資の貸付金 | 約 2,150億円 | 商業総務費の中小企業振興資金融資費（金融機関に預けて年度内に戻る） |
  | その他 | 約 1,200億円 | 残り（事務費・施設の管理・施策別資料に載らない事業） |

  人件費は施策別資料の事項と一部重なりうるので、書き出しでは「歳出 − 施策別資料の事項 − 上の4つ」を その他 にし、重なりを数えて
  「データについて」に書く（負になれば止める）
- **補正予算は入れない**（最初の版）: 柱・取組の分類は当初の施策別資料にしかなく、補正の事項を取組に置けない。名前で当初の事項に寄せても、
  R8 の補正の歳出の事項 24件のうち同じ名前は 2件（3.4億円）だけ（補正で足す事業は新しい名前が多い）。額も R8 の4回で約 130億円（当初の 0.6%）。
  後で「補正で足した事業（取組の分類なし）」のグループとして横に足せる形にしておく
- 金額は当初予算の額（千円 → 円にして書き出す。共通 JSON 形式の金額は1円単位）

## 4. データ（書き出し）

- 当初予算のファイル（`budget-2026-initial.json`）に `policies`（施策別資料の事項の一覧）を足す。1件:
  `{ pillar, initiative, division（課名）, kamoku: [{kan, kou, moku}], name, amount, previous, is_new, notes, source: {doc, page} }`
- 結び付け:
  - **事項 → 目**（科目）。詳細パネルから、サンキー図のその目へ移れる。科目が複数の事項（2.6%）は全部の目に結ぶ（金額は分けない）
  - 説明書の説明欄の事項とは **多対1**（施策別資料の事項のほうが細かい）。名前と金額が一致するものだけ直接結ぶ（今の試算で 67件）。それ以外は目まで
- 検算: 目ごとの事項の合計が目の額を超えないか（今の抽出で 3目が超える → 5章）。柱・取組ごとの合計を出して「データについて」に載せる
- `unstable_cache` は使っていない（静的ファイル）。スキーマの版を上げ、`validate.ts` に `policies` の確かめを足す

## 5. 先に直す抽出の崩れ（今の `shisaku.json` で見つけた）

| 崩れ | 件数 | 直し方 |
|---|---|---|
| 科目が複数行にわたると、数字が行ごとに割れる（「ワンヘルス教育推進費」`['5 3 1','1 4','10 8 1','9 2']`） | 120 | 科目の欄を文字の位置（x）で款・項・目の列に分けて読む |
| 区分が空（p27 の人権の事項 6件） | 6 | 区分の見出しの読み方を直す（ページの頭の続き） |
| 柱がない（区分「地方分権の推進」） | 36 | 施策別資料の構成を確かめ、柱の外のグループ「計画の推進」とするか決める（7章） |
| 目ごとの合計が目の額を超える（体育振興費 10-7-2: 事項 12.6億 / 目 5.4億） | 3目 | 「県立体育・スポーツ施設費」7.2億の科目の読み違いの見込み。画像で確かめて修正表へ |
| 科目に「外」（他会計・債務負担行為の印） | 3 | 意味を確かめる |
| 柱 2 の名前が行の途中で切れる（2行の見出しの2行目を読んでいない） | 827件分 | 見出しの2行目をつなぐ（2行目は資料で確かめる。表の名前は見込み） |

## 6. 画面（案）

- 場所: `/local/[gov]` の見方に「施策（バブル図）」を足す（サンキー図と同じ年度・データの選び方）
- 配置: `d3-hierarchy` の `pack`（入れ子の円。柱 → 取組 → 事項）。国版の `BubbleCanvas`（文章の埋め込みの配置）は使わない
- 大きさ: 面積を金額に比例（円の半径は √金額）。**上位 10件で 55%**（後期高齢者医療負担金 905億・介護給付費負担金 671億…）を占め、
  1億円未満が 755件あるので、義務的な負担金を外して見るスイッチを付ける（案。外した額は表示する）
- 色: 柱ごと（4色 + 柱なし）。款で色分けする切り替えも付ける（款をまたぐ広がりを見るため）
- 操作: 取組の円を押すと拡大（中の事項が読める）。事項を押すと詳細パネル。取組の一覧（合計の多い順）を横に出す
- 補正後: 施策別資料は当初だけなので、バブル図は当初予算だけ。補正後の見方では出さない（一般財源の中身の表と同じ扱い。3章）
- 載らない経費: 灰色の円（3章の5つ）を柱の円の外に並べる。押すと中身の説明（款・節・数え方）

## 7. 決めたこと（2026-11-20 ユーザー承認）

1. **範囲**: 一般会計だけ・債務負担行為を除く。補正予算は最初の版では入れない（3章）
2. **載らない経費**（約 1兆5,000億円）: 中身ごとに灰色の円に分けて見せる（3章の表）
3. **巨大な事項**（義務的な負担金）: 面積比例のまま＋外すスイッチ（外した額は表示）
4. **柱なしの「地方分権の推進」**: 柱の外のグループとして出す
5. **色**: 柱ごと（既定）＋款の切り替え
6. **作業の順**: 5章の抽出の直し → 書き出し（4章）→ 画面（6章）。PR は「抽出と書き出し」「画面」の2つに分ける
7. **ブランチ**: `feat/fukuoka-bubble`（local-main から）
