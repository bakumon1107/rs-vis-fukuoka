## 2. 変えること（案）

### 2.1 選んだ箱の内訳の表

款・項・財源・歳入の款・会計を選んだら、図の下（スマートフォンはシート）に **その箱から右へ出る内訳の表** を出す。

| 選んだ箱 | 表の行 |
|----------|--------|
| 財源（国庫支出金など） | その財源が入る款（款ごとの額） |
| 款 | 款の中の項 |
| 項 | 項の中の目 |
| 歳入の款（全会計） | 入る会計 |
| 会計（全会計） | 会計の中の款 |

- 行は金額の大きい順、帯の長さつき（かんたんの一覧と同じ見た目。`SimpleRanking` を「列」でなく「選んだ箱の子」で並べる形に広げる）
- 見出しに選んだ箱の名前と額、表の上に「◯◯の内訳（款ごと）」
- 行の名前を押すと、その箱を選ぶ（項→目と下りていける）
- 額は**図の右へ出る帯の額**（図と同じ数字。推計なし）。図を3列に絞っていても、表は絞る前の全部の帯から作る
- 一般財源を選んだときは、今の一般財源の中身の表の下にこの表を足す
- 公営企業会計の見方の右の列（金額を出さない列）は、表も出さない

### 2.2 前年度比

**当初予算（一般会計・特別会計）の見方だけ** に出す。

- 表の各行と見出しに「前年度 ◯◯億円・増減 +◯◯億円（+◯.◯%）」
- 款・項・目・歳入の款・会計: 目の前年度を足した額
- 財源の箱は前年度の額がないので出さない（「財源の内訳は前年度の資料にないため」と注記）
- 補正後・決算の見方は前年度の額がないので出さない。補正後は今の「当初からの増減」がそのまま出る
- 図の箱のラベルには出さない（今の補正の増減の印と並ぶと読みにくい。表とツールチップに出す）

**別案**（採らない）: 令和7年度の当初予算を取り込んで、財源まで前年度比を出す。説明書を1年分読み取り直すことになり、手間が大きい。
目の前年度で款・項は出せるので、まずはそれで足りるか見てから考える。

## 3. 変更するファイル（見込み）

- `app/lib/local-gov/`: 選んだ箱の子の一覧（図の帯から）と、箱ごとの前年度の額（目の `previous` を `rowBoxIds` で足す）の純粋関数
- `client/components/local-gov/`: 内訳の表（`SimpleRanking` を広げるか、共通の行の部品を切り出す）
- `app/local/[gov]/page.tsx`: 目以外を選んだときに表を出す
- テスト: 款・項の前年度の合計が目の前年度の合計と合う・表の合計が選んだ箱の額と合う

## 4.5 決まったこと（2026-11-28 ユーザー了承「一旦それで良いよ」）と、作りながら決めたこと

- 表は右へ出る内訳だけ。前年度比は当初予算（補正を足していない）だけで、財源には出さない。#24 をマージしてから作った
- **公営企業会計の見方にも表を出す**（2.1 では会計・条の列には出さないとしたが、金額を出さないのは図のラベルが重なるためで、
  表なら重ならない。会計・条を選ぶと支出の項と収支の差の箱が並ぶ）
- 行の補正の増減・前年度比は、**行の箱の全部が選んだ箱に入る行だけ**（款 → 項、項 → 目、会計 → 款）。財源 → 款・歳入の款 → 会計の
  行は帯の額（一部）なので、箱全体の数字を添えると帯の増減に見える。表の上に「この表の額は◯◯から入る分だけなので…」と書く
- かんたんの図の下の一覧にも、同じ行の部品で前年度比を出す
- 前年度の額の確かめ: 会計ごとに前年度の歳入の合計 = 歳出の合計（実装と別の性質）。県営埠頭施設の特別会計だけ 2,530千円
  合わなかった。前年度にだけあった款「財産収入」が総括表にしか載らず、行がないため（福岡県の README「資料の癖」）。
  全会計の見方の歳入の款「財産収入」の前年度がこの分だけ小さい。データの直しは別に考える

## 5. 決めてほしいこと（4.5 で決まった）

1. 表に出す行は **右へ出る内訳だけ** でよいか（款を選んだとき、左の財源ごとの額は出さない。必要なら下に足せる）
2. 前年度比は **当初予算だけ・財源は出さない** でよいか（財源まで出すなら令和7年度当初の取り込みが要る）
